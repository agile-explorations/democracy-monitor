# Democracy Monitor — Future Roadmap

Democracy Monitor is an open-source platform that detects democratic erosion signals by analyzing the U.S. government's own documentary record. The system reads hundreds of thousands of government documents — federal regulations, court filings, DOJ enforcement actions, presidential statements, inspector general reports, legislative bills, congressional floor speeches, and election commission records — and uses AI document content assessment as the sole status-driving detection layer, plus descriptive analytics (government silence detection, structural composition metrics, and thematic drift tracking) to identify patterns that warrant public attention.

The current system monitors 14 democratic threat vector categories with documents from 9 primary sources across a continuous record from 2017 to present (9 periods: Trump_2017 through Trump_T2, with gap year backfill complete). After two sprints — R-CONTENT (content enrichment, routing expansion, boilerplate stripping, P1/P2 window increases) and R-CALIBRATE (P1 description tightening, NC threshold reframing) — it detects 39/39 known erosion events (100%) with 6/6 negative controls passing. Zero failures.

This roadmap describes four planned releases that extend the platform's analytical capabilities. Each addresses a distinct gap in democratic oversight that no existing tool fills.

**Release order and rationale:**

1. **Detection Quality & Platform Hardening** — foundation must be solid before building on it. Every subsequent release depends on accurate, calibrated detection. Content enrichment and calibration sprints revealed two fundamental insights: (1) the primary constraint on detection quality is data coverage, not scoring precision — several known erosion events are invisible because they were announced through rhetoric and media channels, not formal government documents; (2) the L1 structural anomaly layer and L3 thematic drift layer are correlates of erosion, not signals of erosion — they measure statistical artifacts (volume differences between administrations, topic changes over time) rather than direct evidence. The detection architecture has been redesigned around two layers with a defensible connection to democratic erosion: **L2 content assessment** (do the documents describe concerning actions?) and **L1v2 silence detection** (has the government stopped producing documents in an area where non-government sources are active?). Structural composition metrics and thematic drift are preserved as descriptive context for narratives and research, not as scoring inputs. Source expansion (Congressional Record, pulled forward from Release 3) accompanies the architectural changes. Data page is implemented. Balance of Powers Phase A and public API are not started.
2. **Authoritarian Infrastructure Build-out** — the most genuinely novel contribution in the roadmap. Existing organizations track what the government says (rhetoric), what it decides (executive orders, court rulings), and whether it follows a published plan (P2025 trackers). Nobody systematically tracks whether the government is building the operational capacity to act at scale — the personnel pipeline, the surveillance technology, the information control apparatus, and the funding that would make authoritarian action possible. Detention _utilization_ is well-tracked by existing organizations (Deportation Data Project, Detention Reports), but detention _capacity_ (how many beds the government has contracted for) is a genuine data gap — ICE stopped publishing facility characteristics in late 2024, and no single public dataset of contracted beds per facility exists. Democracy Monitor's unique value is in the dimensions nobody else watches — **personnel buildup** (USAJobs hiring surges by agency), **surveillance procurement** (SAM.gov technology contracts), **information control** (FOIA degradation, government data removal), **interagency enforcement network expansion** (287(g) agreements, data-sharing pipelines), and the **cross-feature convergence** connecting infrastructure data to the document analysis pipeline. For detention, triangulate capacity from SAM.gov contracts, TRAC snapshots, congressional appropriations, and utilization data from DDP and Detention Reports. The simplest components (USAJobs API, SAM.gov contracts) can be pulled forward as standalone source additions, the way CREC was pulled from Release 3 into Release 1.
3. **Rhetoric vs. Action** — CREC (congressional rhetoric) and CPD (presidential rhetoric) already deliver value through the existing pipeline. Phase 1 sources — Truth Social (CNN archive, structured JSON, easiest integration), APP press conference transcripts, State/DHS newsrooms — deliver value immediately through the existing pipeline. Phase 1 also includes a rhetoric routing enhancement (document reference → entity reference → link resolution → keyword fallback) that makes category assignments for rhetoric documents much cleaner than pure keyword matching. Phase 2a ships standalone dashboards — rhetoric intensity, action intensity, side-by-side timelines with ring color coding, ring volume by category — all valuable without any matching. Phase 2b adds a gamified expert matching tool where experts draw connections between rhetoric and action documents; each connection immediately updates lag distributions, ring-to-ring timing, and correlation metrics, with active learning improving suggestions. Phase 2c automates matching only if ≥500 expert-confirmed pairs produce ≥80% precision. Ring analysis is restored: ring classification is trivial (source-based), volume-by-ring visualization is Phase 2a, expert-confirmed ring propagation is Phase 2b, automated propagation detection is Phase 2c. **Each phase delivers value without depending on the next.**
4. **Balance of Powers & Democracy Index Evidence Mapping** — Phase A (Release 1) generates inter-branch check classification data and surfaces "Checks Activated" panels in category pages — this enriches narratives and is worth doing. The Democracy Index Evidence Mapping (connecting V-Dem and Freedom House scores to documentary evidence for independent verification) is the most genuinely novel piece — nobody else provides the primary-source documents alongside democracy index scores so researchers can evaluate those assessments for themselves. **However, the full Balance of Powers visualization (three-branch triangle, constraint rates, historical trajectory) carries "well, duh" risk** — during the current period, courts blocking executive actions and Congress holding hearings is front-page news. The visualization would show what informed citizens already see. The scenario where it adds genuine insight is when constraint rates silently decline — but that's silence detection applied to inter-branch relationships, with the same noise-vs-signal problems we encountered in L1v2. **Ship Phase A and the V-Dem/Freedom House evidence mapping. Defer the full Balance of Powers visualization until empirical data from Phase A demonstrates that constraint rate metrics tell you something the narratives don't already say.**
5. **Project 2025: Plan vs. Delivered** — existing trackers (Project 2025 Observer with 320 objectives across 34 agencies, Center for Progressive Reform) handle comprehensive status tracking well. Democracy Monitor's unique value is narrow: documentary evidence linking, EXCEEDS detection, and cross-feature convergence. The EXCEEDS detection is interesting but hard to validate. The cross-feature convergence depends on other releases existing first. Build it last among the analytical features, build it small, and focus on what the manual trackers can't provide.
6. **State-Level Research Corpus** — extends the documentary evidence base to state legislatures, state courts, and governor executive orders, focused on voter suppression, election administration, civil liberties restrictions, and gerrymandering. A research corpus (downloadable data, API access, search) rather than a detection expansion. Governor executive orders — which no one currently aggregates across all 50 states in machine-readable form — are addressed through an AI-powered self-healing scraper system. State selection informed by Release 4's Democracy Index Evidence Mapping, which identifies which states V-Dem and Freedom House flag for declining democratic quality.

## Release 1: Detection Quality & Platform Hardening

### Why It Matters

A democracy monitoring tool is only as credible as its accuracy. False positives erode trust ("the system cries wolf"), false negatives create blind spots ("the system missed something important"), and data quality issues undermine every downstream analysis. Before adding new features, the platform must achieve the highest possible detection accuracy on events the public record already contains.

The system detects 39/39 known democratic erosion events (100%) across both Trump administrations (2017-2018 and 2025-present), including 35 exact-week detections and 4 latency detections (detected in the following week), with 6/6 negative controls passing. Sprint R-CONTENT (content enrichment and routing expansion) eliminated all prior misses — source gaps, routing gaps, thin-category issues, and P2 dismissals were all resolved, taking detection from 22/39 (56%) to 39/39 (100%). Sprint R-CALIBRATE brought negative controls back into compliance through P1 description tightening (civilLiberties and judicialIndependence threat-vector framing with explicit "NOT erosion" exclusions), NC-5 reframing (baseline-period P2 calibration instead of T2 ceiling — the T2 period is genuinely, continuously active with 270 category-weeks of real erosion outside the 25 known events), and threshold adjustments grounded in empirical verification that elevated baseline-period weeks contain genuine content (Title 42 legislation, NDAA civil liberties provisions, patronage prevention legislation).

This release closes every gap that can be closed with the existing source stack, builds the operational infrastructure for ongoing accuracy improvement, and establishes the human review processes that keep the system honest.

### Key Features

**L1v2: Silence detection. Status: Implemented.** See `lib/services/silence-detection-service.ts`. Intra-admin 8-week rolling window, government vs. independent source classification, conspicuous silence flag (gov z > 1.5σ + independent active), integrated into convergence synthesis. Multiple calibration sprints revealed that the L1 structural anomaly layer's core approach — comparing weekly document volume and composition against historical baselines from a different administration — conflates three unrelated signals: administration style differences (Trump produces 5x more executive actions than Biden), congressional calendar effects (NDAA week, budget fights), and genuine information suppression. Only the third has a defensible connection to democratic erosion. Per-category thresholds, dampening curves, cycle-year matching, and source filtering were each attempted and each created new problems, because the fundamental question ("is this week statistically different from Biden Year N?") is the wrong question for cross-administration monitoring.

L1v2 replaces volume-against-historical-baseline with a focused question: **has the government gone silent in an area where non-government sources remain active?** When executive-branch-controlled sources (Federal Register, DOJ, CPD, OIG) cease producing documents in a category — but independent-branch sources (CREC congressional speeches, CourtListener judicial filings) show continued or elevated activity — the contrast between government silence and public discourse is a direct signal of potential information suppression that no document-level analysis can provide.

The design:

- **Government-source volume** compared against a short rolling window (8-12 weeks within the current administration), not against a historical baseline from a different president. Eliminates the cross-administration baseline problem entirely.
- **Conspicuous silence score** — the ratio of government silence to non-government activity per category per week. High CREC + low government = suspicious. High CREC + high government = active policy area. Low CREC + low government = genuinely quiet topic.
- **Source health gate** — silence only counts as a signal when the pipeline confirms it successfully reached the source and got zero results. Prevents API outages from triggering false "government is hiding something" signals. Source health monitoring is a hard prerequisite.
- **Cold-start fallback** — during the first 8 weeks of a new administration (before the rolling window has enough data), use cycle-year baseline as fallback.

L1v2 makes CREC a feature rather than a liability: congressional rhetoric is the contrast signal that gives government silence its meaning, not a volume contributor that contaminates structural baselines.

**L1 structural dimensions preserved as descriptive context. Status: Implemented.** Structural dimensions computed but excluded from convergence scoring. The current L1 computes six dimensions: volume, typeComposition, functionalDistribution, agencyActivity, publicationTempo, and sourceConvergence. These are correlates of erosion events — when OPM publishes the RIF rule, agency activity concentration spikes — but the spike is an artifact of the event, not evidence of the event. L2 reading the rule and identifying the removal of grievance rights is the evidence. Multiple calibration sprints confirmed that these dimensions cannot independently distinguish erosion from routine governance variation. They are preserved as descriptive metadata for narratives ("OPM dominated this category this week," "document types shifted from notices toward executive orders") and future visualization, but removed from convergence scoring. They should not independently drive elevation status.

**L3 thematic drift demoted to descriptive context. Status: Implemented.** L3 has zero independent detections across all known events, a 44% false positive rate before cleanup, and has been in reinforcement-only mode for its entire operational life. The core limitation is architectural: thematic drift measures topic change, not erosion. The embedding centroid shifts when an administration changes policy focus — but it shifts identically whether the policy weakens protections or strengthens them, because that distinction is in the document content, not the embedding geometry. L3 cannot distinguish "restructuring to weaken merit protections" from "restructuring to strengthen merit protections." Assessment of what drift _means_ requires reading the documents, which is L2's job.

Thematic drift metrics continue to be computed (they're cheap — cosine distance between centroids) and serve three valuable purposes: (1) narrative enrichment ("this week's documents shifted from oversight language toward efficiency language"), (2) research mode visualization (thematic trajectory over time, drift-driving documents identified), and (3) Release 4 Balance of Powers historical trajectory. But thematic drift is removed from convergence scoring — it does not contribute to elevation status, not independently and not as reinforcement.

**The simplified detection architecture. Status: Implemented. This is the current production architecture.**

- **L2 (content assessment):** Primary detection layer. With contextual P2 (peer titles, P1 flag counts, document's own P1 result, rhetoric framing for CREC), L2 reads the documents and determines whether they're concerning. Catches erosion events where documents exist that describe concerning actions — executive orders restructuring agencies, rules removing grievance rights, personnel action letters, IG termination notices.
- **L1v2 (silence detection, descriptive):** Surfaces the one signal L2 cannot — the _absence_ of expected government output — as narrative/context data. It does not drive concern status. Includes a sparse-source mode (presence-rate/zero-streak test) for categories averaging under 3 docs/week.
- **Descriptive context (not scoring):** Structural composition metrics (type/agency/tempo) and thematic drift enrich narratives and research tools but do not drive elevation status.

**Transition plan: Complete.** Completed across sprints R-CONTENT, R-CALIBRATE, and subsequent implementation work. L3 demoted, L1 structural demoted, contextual P2 (B-E) shipped, L1v2 silence detection implemented. The current production system: L2 content assessment is the sole status driver; silence, structural, and thematic layers are descriptive context.

**Admin review queue. Status: Not started (admin auth exists — pages/api/admin/login.ts session-cookie auth serves the feedback page; the review queue itself is the remaining build).** Human review of AI assessments is essential for ongoing calibration. When the AI flags a document as concerning, a domain expert should be able to confirm, override, or provide context. These decisions feed back into the system's understanding of what constitutes genuine erosion versus routine governance. The review queue surfaces the AI's work for human judgment without requiring humans to read every document.

**Feedback learning pipeline. Status: Not started. Depends on review queue.** Systematic capture of human review decisions to improve detection over time. When reviewers consistently override the AI on a particular type of document (e.g., routine SEC filings that trigger false positives), the system proposes prompt adjustments or threshold changes. Every proposed change is human-approved and version-controlled — the system never silently modifies its own methodology.

**Additional data sources.** Three supplementary sources that fill specific category gaps: Oversight.gov IG reports (when an API becomes available or scraping proves reliable for all 75 IGs), Voting Rights Lab calibration data for LegiScan classification accuracy, and CBO reports for the fiscal category.

**Priority source expansion (pulled forward from Release 3).** Regression analysis across multiple calibration sprints revealed that the primary constraint on detection quality is data coverage, not scoring precision. Thin categories underperform because they have too few documents, and several known erosion events (Comey firing, DOGE operations, DOJ career firings) are invisible because the actions were announced through rhetoric and media channels, not formal government documents. Further threshold tuning produces diminishing returns; more data produces compounding returns. Two sources from Release 3 Phase 1 are pulled into Release 1 because they deliver immediate detection improvement through the existing pipeline:

- **Congressional Record (CREC) via GovInfo API.** The single highest-value source addition. 75-491 speaker-parsed floor speeches per week across all 5 analysis periods. Routes into every category through content-based classification. Makes personnel actions, policy announcements, and institutional conflicts visible before they appear in formal documents — the Comey firing was debated on the Senate floor, DOGE was discussed in floor speeches weeks before it entered agency offices, Schedule F was the subject of congressional testimony. Requires speaker parsing (solved problem — Stanford's Congressional Speech Dataset validated the approach) and the `speaker` field on documents.

- **DOJ AG speeches and testimony.** ~~Extends the existing DOJ API integration to include speeches and congressional testimony, not just press releases. Small work — same API, different document type filter.~~ **Blocked:** The DOJ API only exposes `/api/v1/press_releases.json` and `/api/v1/blog_entries.json`. No speeches or testimony endpoint exists. AG speeches would require HTML scraping of justice.gov, which has no stable archive structure. Deferred to Release 3 alongside other HTML-scraping sources (State/DHS newsrooms).

CREC is ingested through the existing pipeline (fetch → score → L2 → embed → aggregate) and participates in all detection layers immediately. The Release 3 analytical features (lag analysis, matched-pairs, speaker tracking) are built later on top of the data these sources provide.

**Contextual P2 prompt enhancement (B-E variant — spike validated).** P2 previously evaluated each document in isolation. A P2 variant spike tested 5 prompt configurations against 24 missed documents, 75 correctly-assessed documents, and 37 baseline documents. The B-E variant — within-category context (expert description, document count vs. baseline, recent trajectory, P1 flag count, flagged peer titles with erosion types, document's own P1 result) plus rhetoric framing for CREC floor speeches ("assess whether the rhetoric signals institutional pressure, policy intent, or erosion framing") — was the only variant with a positive net score (+3): 6/24 misses recovered, 2/75 regressions, 1/37 baseline false positives.

Key spike findings: (1) B-full (peer context without rhetoric framing) regressed badly — 12/75 regressions, especially on DACA/immigration speeches where peer context caused P2 to view individual speeches as "one of many" and dismiss them as routine. (2) B-prior (adding prior-week context) was actively harmful — 18/75 regressions, worst of any variant; more context caused P2 to over-contextualize and dismiss documents that should be flagged. (3) The rhetoric framing in B-E is what corrects B-full's regression problem — it prevents P2 from dismissing congressional rhetoric about institutional pressure as "not a formal action." This framing is necessary for any system that includes CREC floor speeches.

Cross-referencing B-E's 6 flipped documents against latency analysis revealed that only 1 of the 6 targets a category-week that is a true detection miss (T2-8 judicialIndependence). The other 5 strengthen signals in categories already detected at Elevated or higher. The category-level detection improvement is minimal, but B-E serves three purposes beyond the headline number: improved document-level accuracy for narratives (P2 correctly flags specific EOs and speeches that appear in published narratives), correctness for CREC source type (floor speeches require rhetoric-aware assessment), and prerequisite for L1 structural demotion (contextual P2 must be running on the full corpus to measure whether aggregate L2 z-scores cross threshold on the 5 L1-only detection weeks).

Prompt engineering has a ceiling for P2 improvement — the P2 variant spike showed 18 of 24 missed documents were not recovered by any variant. The R-CONTENT sprint resolved those misses through content fixes (P1/P2 window increases, boilerplate stripping) and routing expansion (CPD subject mappings, CREC topic terms, FR agency routing fixes) rather than further prompt changes, validating the regression analysis finding that data coverage was the binding constraint. Detection is now at 100% (39/39). The remaining quality work is calibration — reducing false positive rates without losing detections.

**Validation harness latency window.** 4 of 39 known events are detected at Elevated or higher in the week following the event rather than the event week itself — the system detects the institutional reaction (congressional floor speeches, oversight hearings, related filings) rather than the action itself. T1-1 Travel ban TRO filings (judicialIndependence), T1-5 Family separation (civilLiberties, lawEnforcement), T2-12 Government shutdown workforce (civilService). The validation harness counts events detected within one week as detections with a latency note.

**Thin-category detection (resolved by L1v2 + contextual P2).** Categories averaging under 10 documents per week (judicialIndependence, elections, hatch, mediaFreedom) were poorly served by the volume-sensitive L1v1 scoring machinery, where dampening and raised thresholds created a catch-22. The L1v2 silence detection architecture resolves this: thin categories are where government silence is most detectable (a category producing 6 docs/week that drops to 0 is a clearer signal than a category producing 300 that drops to 250). Contextual P2 addresses the content-assessment gap by giving P2 the week context needed to assess documents in thin categories where every document matters more.

**Event retrospective harness. Status: Implemented.** See `lib/validation/retrospective.ts`. A reusable tool for running known events through the complete detection pipeline retrospectively. When a new event occurs, the harness shows which layers detected it, which documents drove the detection, and what the system would have reported. This produces public methodology documentation, calibration benchmarks, and credibility artifacts for the open-source community.

**Cross-category synchrony detection. Status: Partial.** Per-week elevation aggregation exists in `overview-service.ts`. No cross-category causal meta-signal detection. When multiple categories are simultaneously elevated — civilService, executiveOversight, and judicialIndependence all flagged in the same week — that cross-category pattern is itself a signal above the sum of individual categories. This meta-signal detects coordinated institutional pressure that individual category monitors cannot see.

**Media coverage as independent signal. Status: Not started. Consider deferring to Release 2.** Media coverage patterns — not the content of coverage, but the _patterns_ of coverage — are democracy health indicators. When a topic that normally generates diverse coverage across 30 outlets suddenly shows identical framing across 25 of them, something is shaping coverage. When a major government action generates almost no media scrutiny because the news cycle is dominated by something else, the absence of scrutiny is informative. This feature builds media-specific structural dimensions, media-specific baselines, and integrates media scrutiny as a convergence input alongside government document analysis.

**Data page and public API (`/data`). Data page status: Implemented.** CSV exports and DB dump available at /data. **Public REST API status: Not started.** Democracy Monitor's credibility depends on the data being freely available for verification, research, and reuse. The `/data` page is a top-level navigation item (not buried in methodology or footer) that provides three access tiers:

- **Weekly aggregates CSV** — one row per category per week with convergence status, structural metrics, thematic drift scores, AI assessment summaries, document counts by source. Updated weekly. Best for researchers, journalists, and anyone analyzing trends without running the full system.
- **Full database dump (GitHub Release)** — complete PostgreSQL dump including all documents, AI assessments, embeddings, and computed scores. Updated weekly. Best for developers, contributors, and anyone reproducing the analysis or running Democracy Monitor locally.
- **Public REST API** — programmatic access to documents, weekly aggregates, category summaries, and search. Paginated, filterable by category, source, date range, and state (when state-level data is available). Rate-limited for public access, with API key registration for higher-volume use. The API is foundational infrastructure that the Data page, Research Mode, and future integrations (Release 4 V-Dem evidence mapping, Release 6 state-level corpus) all depend on.

The framing: "Democracy Monitor is open data. Here's what we have and how to use it." Prominent data access supports the GitHub Sponsors messaging — "this is what your sponsorship supports: a free, open dataset tracking democratic institutions."

**Platform polish. Status: Not started.** First-time visitor onboarding, mobile-responsive layouts, performance optimization, and the ongoing UI improvements that make the system accessible to non-technical users.

**Gap year backfill (corpus completeness). Status: Complete (July 2026).** The system originally covered five periods (Trump_2017, Trump_2018, Biden_2021, Biden_2022, Trump_T2) with two multi-year gaps. All eight baseline periods are now active analysis periods with full L2 coverage, and the July 2026 coverage-parity work (court-scoped opinions 2017→present, LegiScan full terms, substantive-only counts) made the 9-year record uniform — see docs/internal/COVERAGE_PARITY_AUDIT.md.

**CourtListener bulk data infrastructure (completed during backfill).** Major infrastructure addition: CourtListener bulk data staging tables, opinion-first search integrated into all three CL pipelines (backfill, snapshot, backfill:opinions), hybrid API + local-DB approach eliminating rate limiting, full-text opinions replacing 8KB-truncated API text. This is operational infrastructure that affects all future CourtListener data processing — not just backfill. This continuous corpus is not just more data — it enables a fundamentally new capability: **the corpus itself becomes the sensor for detecting shifts in government reporting patterns.** Volume changes, document type composition shifts, content quality degradation, source disappearances, category coverage gaps, semantic narrowing, and publication timing anomalies are all detectable from a 9-year baseline of consistently-gathered documents from the same sources. See "The corpus itself is the sensor" in the Release 2 Analytical Principles for the full list of detection capabilities. **Trump 2019-2020** contains the most important validation events: Ukraine/impeachment (2019), COVID emergency powers (2020), first Schedule F executive order (October 2020), post-election challenges and January 6 lead-up (late 2020). Impeachment is the single best test case for multiple features: checks-and-balances event (Release 4), months of rhetoric preceding formal action (Release 3), IG involvement (Ukraine whistleblower). COVID tests the system's ability to distinguish genuine emergency response from executive overreach. **Biden 2023-2024** completes the continuous record — mostly routine governance, but essential for cross-administration baseline comparison and for the research corpus. Each gap requires its own L2 run on the ingested documents and expands the validation harness known-events list.

### Release 2 Items Under Consideration for Early Execution

The following infrastructure corpus expansion items are Release 2 features that immediately improve Release 1's existing product (specifically Research mode answers) as soon as the documents are ingested. They require no Release 2 feature build — just corpus expansion using existing pipeline infrastructure. None have been started.

**Infrastructure corpus expansion (Release 1 enhancement).** Some infrastructure data sources identified in the Release 2 research immediately improve Release 1's existing product — specifically Research mode answers. Today, a user asking "which agencies experienced the largest reductions under DOGE" gets policy documents (executive orders, proposed rules, bills) but no outcome data (actual headcount changes). Ingesting OPM Federal Workforce Data into the corpus would add the structured employment data that makes Research answers substantive. The same logic applies across dimensions: SAM.gov contract documents make surveillance procurement searchable, 287(g) MOAs make enforcement agreements findable, EOIR statistics make immigration court data available, and budget documents make funding requests and actual spending searchable. **The convergence dashboard, trend visualizations, and dimension pages are Release 2. The documents themselves improve the existing product as soon as they're ingested.** Corpus expansion from infrastructure data sources should begin as soon as feasible, independent of the Release 2 feature build.

**Budget and spending documents — both plan and execution.** OMB budget documents and spending data together reveal the gap between what the government says it will do and what it actually does. Both are essential:

- **President's Budget Appendix** — published annually through GovInfo (govinfo.gov/app/collection/budget). **Claude Code investigation confirmed: the existing GovInfo fetcher extends trivially (3 code changes), and the Appendix is already broken by agency as separate granules** (e.g., BUDGET-2026-APP-2-11 = DHS, BUDGET-2026-APP-2-14 = DOJ). No programmatic chunking needed — GovInfo did it. 39 granules per fiscal year for the Appendix. FY1996-present in native digital form, consistent structure from ~FY2000 onward. Total volume across all years: 412 packages. Document types: APP (Appendix — per-agency, high-value target), BUD (main budget request), PER (Analytical Perspectives), TAB (Historical Tables), MSR (Mid-Session Review), TRS (Terminations, Reductions, and Savings).
- **Agency Congressional Budget Justifications** — **skip as a separate source.** The GovInfo Budget Appendix granule for each agency already contains the budget section. DHS's own website is WAF-blocked and has inconsistent URLs with typos.
- **Monthly Treasury Statements** — **use the Fiscal Data API, not PDFs.** Treasury's Fiscal Data API (api.fiscaldata.treasury.gov) provides structured JSON with no authentication, going back to 1980, with monthly granularity and per-agency outlays across 16 tables. New fetcher needed but follows the standard module pattern. These showed ICE's outlays jumping from ~$800M/mo to $1.7B/mo post-OBBBA (Bier/CATO analysis).
- **USASpending.gov** — public REST API with bulk download. Contract-level and grant-level data back to FY2001. Over 400 data elements per record. Already granular (one record per contract award) — no chunking needed.
- **OMB apportionment data** — how OBBBA and other funds are allocated across DHS components. Access method still needs investigation (may be PDF-based — this is the question we asked Bier).
- **Public Budget Database (BUDGET-YYYY-DB)** — **the structured data solution for budget-vs-actual comparison.** Claude Code discovered that GovInfo's BUDGET collection includes a DB document type: downloadable XLSX files with account-level budget data. DB-1 = budget authority by agency/bureau/account (FY1976–FY2029 estimates, 1.1 MB). DB-2 = outlays by agency/bureau/account (FY1962–FY2029 estimates, 1.9 MB). DB-3 = receipts by source. Schema per row: agency code, agency name, bureau code, bureau name, account code, account name, Treasury agency code, subfunction code/title, BEA category (mandatory/discretionary), grant/non-grant, on/off budget, then one column per fiscal year with amounts in thousands of dollars. **No PDF extraction needed — clean tabular data.** FY2025 DB is the latest; FY2026 DB may never appear because the administration released only a "skinny budget" without full detail. **The absence of a full FY2026 budget submission is itself an information control signal** — previous administrations occasionally delayed but always published one eventually.

**Budget-vs-actual join strategy (confirmed feasible):**

- **Budget side:** Public Budget Database XLSX → budget authority and estimated outlays by agency, bureau, account
- **Actual side:** Treasury Fiscal Data API → actual outlays by agency, monthly
- **Join key:** Both sources contain Treasury Agency codes (OMB codes differ, but the XLSX includes both)
- **Result:** Programmatic budget-vs-actual comparison by agency by fiscal year — the exact capability needed to detect spending anomalies like the ICE outlay surge ($800M/mo → $1.7B/mo post-OBBBA). FY2025 DB gives actuals through FY2024 and estimates through FY2029; Treasury API provides real-time actual spending regardless of whether a full budget is published.

**Chunking strategy — largely resolved by GovInfo's pre-existing structure:**

The Budget Appendix is already pre-chunked by agency as separate granules. For DHS specifically, the single DHS granule (~100+ pages covering ICE, CBP, TSA, FEMA, etc.) may still benefit from sub-chunking by component/bureau for better routing and embedding quality — ICE detention funding and FEMA disaster relief in the same document will produce mixed signals. This is the one remaining chunking question to resolve during implementation. The general principle remains: **chunk to the level where (a) the chunk maps to one or a few categories, (b) L2 can assess it as a coherent budget request, and (c) embeddings produce useful search vectors.**

- **Budget Appendix:** pre-chunked by agency by GovInfo. DHS granule may need sub-chunking by component (ICE, CBP, TSA, FEMA). Other agency granules (~20-100 pages each) route naturally.
- **Monthly Treasury Statements:** structured JSON via Fiscal Data API — can filter by agency directly. No document-level chunking needed.
- **USASpending.gov contract records:** already granular (one record per contract). No chunking needed.

**Priority order (confirmed by Claude Code investigation):**

1. OPM FWD — visible gap in Research mode today
2. 287(g) MOA PDFs — data sources validated, sprint scope defined
3. Budget Appendix via GovInfo — **existing fetcher extends trivially, per-agency granules are pre-chunked, 30 years of history**
4. Monthly Treasury Statements via Fiscal Data API — **structured JSON, no auth, back to 1980**
5. SAM.gov contracts — public API, surveillance/detention procurement (company-watchlist approach per Poulson)
6. USASpending.gov — contract-level detail, already granular

**Balance of Powers Phase A (inter-branch check classification). Status: Not started.** The current system monitors threats but doesn't surface institutional responses — when a court blocks an executive order, the system sees the order but not the judicial check. Phase A adds a P2.5 classification pass that identifies inter-branch constraint documents (injunctions, oversight reports, rule withdrawals), extracts references to the specific actions being checked, and surfaces a "Checks Activated" panel in category detail pages. This reprocesses existing documents — no new data sources needed. Constraint rates per directional relationship (Judicial → Executive, Legislative → Executive, etc.) are computed against historical baselines, revealing whether checks and balances are strengthening, weakening, or holding steady. Full specification in `BALANCE_OF_POWERS_PROPOSAL.md`.

## Release 2: Authoritarian Infrastructure Build-out

### Why It Matters

Plenty of organizations track what the government _says_ (executive orders, policy statements) and what the government _decides_ (court rulings, enforcement actions). Democracy Monitor already does this across 14 categories. But almost nobody systematically tracks whether the government is quietly building the _operational capacity_ to act at scale — the personnel pipeline, the surveillance technology, the legal authorities, and the funding that would make authoritarian action _possible_ even before any decision to act is made.

This is the capability dimension. It answers a different question than the other releases. Rhetoric vs. Action asks "are officials following through on what they say?" Project 2025 asks "are they following a published plan?" Infrastructure Build-out asks: "even if they haven't done X yet, could they do X tomorrow?"

The distinction matters because infrastructure is often built quietly, through routine procurement and hiring processes that don't generate the kind of headlines or legal challenges that executive orders and court rulings do. 2,000 new ICE officer postings on USAJobs, a facial recognition technology procurement on SAM.gov — each is individually a routine government action. Together, they represent a systematic expansion of enforcement capacity that the public has a right to understand.

### Existing Landscape

**Detention _utilization_ is well-covered by dedicated organizations; detention _capacity_ is a genuine gap.** The Deportation Data Project (UC Berkeley Law) obtains individual-level ICE enforcement data through FOIA litigation — arrests, detention book-ins, deportations — with anonymous unique identifiers across linked tables. Their arrests and detentions data are reliable (encounters and removals have known quality issues documented by DDP). Detention Reports (detentionreports.com) provides facility-level population estimates using Interval ADP calculations from ICE's biweekly data releases. The Vera Institute publishes historical facility-level daily population data on GitHub. The National Immigrant Justice Center maintains FOIA-obtained contracts and inspections for over 1,000 facilities. The ACLU has obtained some capacity data through FOIA litigation (GEO Group's 22,000+ ICE beds across 20 facilities). POGO investigates procurement corruption and contracting scandals at DHS. However, no organization publishes a comprehensive, regularly updated dataset of contracted bed capacity per facility — the answer to "how many people could the government detain tomorrow?" ICE stopped reliably publishing its own facility characteristics list in late 2024, TRAC's April 2025 contractual capacity snapshot (62,913 beds across 181 facilities) is a one-time FOIA production with some values redacted, and private prison companies (CoreCivic, GEO Group) actively claim FOIA Exemption 4 (commercial confidentiality) over contracted bed counts — while simultaneously disclosing bed counts to investors in SEC filings.

**What's NOT covered:** Nobody systematically tracks **personnel buildup** (law enforcement hiring patterns across agencies over time), **surveillance procurement** (technology contracts for facial recognition, border surveillance, social media monitoring, biometric databases as a time series), **information control infrastructure** (systematic degradation of public data access, FOIA response times, government website data removal), **interagency enforcement network expansion** (the rate at which new 287(g) agreements, data-sharing pipelines, and cross-agency databases come online), **detention capacity** (how many beds the government has contracted for — utilization is tracked, but no single source provides contracted capacity over time), or the **cross-dimensional convergence** that connects operational capacity data to document-level erosion detection, P2025 implementation, and rhetoric analysis. Individual journalists cover individual hiring surges and procurement stories, but no organization maintains automated, longitudinal tracking of these dimensions.

### Key Features — Focused on Unique Dimensions

**Personnel build-out tracking (partially unique — enforcement-specific tracking is novel).** Organizational capacity for enforcement at scale, measured through federal hiring data (USAJobs.gov API — job postings by agency, series, grade, location) and budget justifications (GovInfo — staffing targets, academy class sizes, authorized vs. filled positions). When 2,000 new ICE officer postings appear in a single month, that's infrastructure build-out regardless of any accompanying rhetoric. **Data landscape:** OPM launched Federal Workforce Data (FWD) in January 2026, replacing FedScope. Monthly data back to FY2005 with agency-level detail including accessions, separations, and recruitment data. The **Partnership for Public Service** (ourpublicservice.org) actively analyzes FWD data and tracked the ~220,000 net employee reduction since January 2025. They raised transparency concerns when OPM removed DEI-related data fields and when DOGE dismantled the unit responsible for managing FedScope. **What's genuinely unique:** nobody filters for enforcement-specific occupation series (GS-1801 immigration enforcement, GS-1811 criminal investigation, etc.), plots the trends by agency across administrations, and connects them to other infrastructure dimensions. When ICE officer hiring surges alongside detention expansion, surveillance procurement, and 287(g) acceleration, the convergence is the signal. **Additional data sources:** OPM's new FWD site (data.opm.gov) provides raw datasets and USAJobs recruitment data; USASpending.gov tracks personnel spending by agency; ICE training data (academy class sizes, training duration — ICE cut 240 hours / 40% of basic training in early 2026 per news reporting; in July 2026 ICE reportedly extended basic training from 42 to 71 days [US Border News], partially reversing the cut — neither change is yet corroborated by documents in our corpus, since ICE/DHS operational announcements flow through channels we do not ingest; DHS OIG ingestion, planned for this release, is the corroboration path) from news reporting and government documents. **Corpus expansion:** USAJobs postings are full documents — store the complete posting text (duties, qualifications, agency description) in the corpus with embeddings. A researcher searching for "ICE deportation officer hiring" should find the actual job postings. Outreach initiated to Partnership for Public Service (pending response).

**Surveillance infrastructure tracking (genuinely unique).** Technical capacity for monitoring at scale. The metric: surveillance-related spending and capability expansion over time, tracked as a trend across administrations and connected to other infrastructure dimensions. **Corpus expansion:** SAM.gov contract documents (solicitations, justifications, award notices) are full documents — store the complete text in the corpus with embeddings. A journalist investigating Clearview AI's CBP contract should find the sole-source justification and award details, not just a procurement summary.

**Methodology — informed by extensive feedback from Jack Poulson (Tech Inquiry / Widely Reported, April 2026):**

Democracy Monitor is NOT trying to identify specific surveillance threats at the contract level — organizations like Tech Inquiry do that far better. The goal is trend-level convergence detection: is surveillance-related spending accelerating alongside detention expansion, enforcement network growth, and personnel hiring?

**Primary approach: NAICS-tagged procurement as a reproducible trend indicator.** SAM.gov and USASpending.gov filtered by surveillance-relevant NAICS codes, summed by fiscal year, plotted as a trend. NAICS filtering systematically undercounts actual surveillance spending (per Poulson feedback: the category of "surveillance" isn't well-defined, intermediaries obscure end use, multi-item contracts bundle surveillance with other services). But as a trend indicator tracked consistently across administrations, the undercount is acceptable — the ratio between periods is the signal, not the absolute number.

**Critical limitation: asymmetric undercounting.** The constant-undercount assumption fails when an administration deliberately moves surveillance spending to channels that avoid procurement databases — classified contracts, OBBBA slush funds with minimal oversight ($10B unrestricted DHS fund), interagency agreements. This is plausible in the current period. If NAICS-tagged surveillance procurement _declines_ while other indicators show surveillance capacity expanding, the NAICS trend is misleading.

**Detection of asymmetric undercounting: the divergence signal.** Track total agency outlays (Treasury Fiscal Data API) alongside NAICS-tagged procurement. When Treasury shows ICE spending surging from ~$800M/mo to $1.7B/mo while visible surveillance procurement doesn't account for the increase, the divergence between total spending and visible spending is itself the signal. You don't need to identify every hidden contract — you need to show that money is flowing (Treasury confirms it) and surveillance capability is growing (congressional testimony, committee hearings, floor speeches confirm it) while the procurement database can't account for where it's going. This is the information control principle applied to spending: "we used to see X and now we can't" is a finding.

**Enrichment layer (optional, lower priority): company-specific tracking.** A watchlist of known surveillance contractors (Palantir, Clearview AI, Babel Street, Zignal Labs, etc.) tracked by vendor name regardless of NAICS code. This enriches Research mode search results ("what surveillance contracts has ICE signed?") but is not the primary trend detection methodology. **The surveillance taxonomy problem remains an editorial choice for this layer:** restrictive definitions (phone-hacking companies only — Paragon, NSO Group) exclude major tech companies; expansive definitions (any company whose infrastructure enables surveillance) include Google, Amazon, Microsoft. Google holds perhaps the world's largest repository of wiretap-targetable data, built Project Maven, and holds major intelligence community cloud contracts, yet doesn't appear in surveillance-focused databases. Democracy Monitor should be transparent about whatever definition it uses and its limitations.

**Significant known limitation: no news ingestion.** Democracy Monitor ingests only government-published documents. Investigative journalism about surveillance spending (NPR's ICE surveillance reporting, Brennan Center's HSI analysis, Tech Inquiry's contract investigations) does not enter the corpus unless cited in congressional floor speeches or committee testimony. Floor time is controlled by leadership — if the majority supports the administration's surveillance expansion, investigative reporting about it may never reach the floor. Committee testimony IS in the Congressional Record and does include expert witness analysis, but coverage is spotty and politically filtered. **This is the most significant coverage gap for the surveillance dimension specifically.** Per-dimension transparency language: "Our surveillance tracking uses government-published procurement data and spending data. We do not ingest news reporting. Surveillance spending that is moved to classified channels, structured to avoid procurement databases, or reported only by journalists will not appear in our data unless it is cited in congressional floor speeches or committee testimony."

**Contracts absent from public procurement databases.** The CIA's Commercial Cloud Environment (C2E) contract (estimated "tens of billions" ceiling) and the NSA's AWS WildandStormy contract are widely reported but absent from SAM.gov/FPDS. JWCC IS in public procurement (corrected per Poulson). These can only be tracked through the document-level corpus — congressional testimony, FOIA results, and floor speeches that reference them.

**Key contact: Jack Poulson (Tech Inquiry / Widely Reported — jack@techinquiry.org).** Poulson's Influence Explorer mines SAM.gov/FPDS procurement data to expose individual surveillance contracts. **Note: Tech Inquiry is in transition — Poulson is starting a new organization. Do not build dependencies on the Influence Explorer tool.** Poulson does not use LLMs, citing concerns about introducing uncertainty in a domain where trust in claims is already fragile. Democracy Monitor's AI does make claims based on documents, but is disciplined: every claim cites specific documents, the system is explicit about evidentiary limitations, and it offers alternative interpretations. The source documents are always available for readers to evaluate directly. Two rounds of feedback from Poulson (April 2026) significantly shaped this dimension's methodology. The **Immigration Policy Tracking Project** (immpolicytracking.org, Professor Lucas Guttentag at Stanford/Yale) catalogues every Trump immigration policy including surveillance deployments — useful as a reference/linking partner.

**Information control infrastructure (genuinely unique).** Operational capacity to restrict what the public knows, measured through FOIA.gov response time data (public API — processing times by agency, backlog growth, denial rates), government data catalog changes (data.gov dataset removal tracking), and government website monitoring (systematic comparison of agency websites against archived versions to detect data removal). When FOIA response times at DHS double while request volume stays flat, when EPA removes climate datasets from public access, when agency statistical publications stop being updated — that's building the information control apparatus that enables enforcement actions to proceed without public scrutiny. A concrete example already observed: ICE stopped reliably publishing its facility characteristics list in late 2024, eliminating public visibility into detention capacity precisely as the system began its most rapid expansion — not a formal policy change restricting transparency, but an operational degradation where data that used to be published quietly stopped appearing. Additional concrete examples from 2025-2026: EPA axing FOIA expedited processing for marginalized communities, DHS's FOIA rule change eliminating paper filing and allowing administrative closure of requests (ILRC submitted comments opposing), US withdrawal from the Open Government Partnership, and the State Department's FOIA backlog jumping 30% in FY2025.

**Key partners for information control:**

- **National Security Archive** (nsarchive.gwu.edu, George Washington University, Director: Tom Blanton) — tracks government transparency degradation events including data removal, FOIA policy changes, and classification overreach. Their UNREDACTED blog documents specific incidents. Outreach initiated (pending response).
- **FOIA Advisor** (foiaadvisor.com, Allan Blutstein) — monitors FOIA annual report data, processing times, and backlog metrics across agencies. Noted DHS/DOJ/DOD missed March 2026 deadline for FY2025 FOIA reports.

- **Reporters Committee for Freedom of the Press** (rcfp.org) — tracks press freedom and FOIA litigation.
- **GAO** — published March 2026 testimony on FOIA backlogs and government data transparency challenges (GAO-26-109034).

This dimension is distinct from the existing infoAvailability category, which tracks formal transparency policy changes. Information control infrastructure tracks the _operational degradation_ of information access — the quiet removal of data, the slowdown of legally required responses, the disappearance of statistical publications. **The 9-year continuous corpus is the primary sensor for this dimension.** With consistently-gathered documents from the same government sources across four administration-periods, changes in volume, type composition, content quality, source availability, category coverage, semantic diversity, and publication timing are all detectable from the corpus itself — no external data needed. See "The corpus itself is the sensor" in the Analytical Principles section for the full list of detection capabilities. This also connects to L1v2 silence detection (Release 1B), which implements the weekly version of the same pattern-change detection.

**Interagency enforcement network expansion (genuinely unique).** Connective tissue that enables enforcement at scale, measured through 287(g) agreement tracking, data-sharing agreements between federal agencies (DHS-SSA, DHS-state DMVs), and facial recognition / biometric database interoperability agreements. The 287(g) expansion rate is extraordinary and well-documented through ILRC's "Immigration Dragnet" policy brief (July 2025) and ICE's own published data:

- **December 2024:** 135 total agreements (60 JEM in 16 states, 75 WSO in 11 states, zero TFM)
- **Week of Feb 24, 2025:** 140 new agreements signed in a single week
- **July 22, 2025:** 832 total (117 JEM in 26 states, 300 WSO in 35 states, 415 TFM in 31 states)
- **March 30, 2026:** 1,586 total (159 JEM in 30 states, 479 WSO in 34 states, 948 TFM in 32 states)

This is a 12x expansion in 15 months. The Task Force Model — previously discontinued by the Obama administration after DOJ investigations found it led to widespread racial profiling — went from zero to 948, making it the dominant model. The TFM is the broadest: officers can screen and interrogate anyone, detained or not, who they suspect lacks lawful status, and arrest noncitizens without a warrant during routine police activity.

**Critical repurposing signal: expansion beyond traditional law enforcement.** The 287(g) network is no longer limited to county sheriffs running jails. In Florida alone, ICE has signed agreements with twelve college and university police departments (FAU, UF, UCF, USF), Fish and Wildlife Conservation Commission, Gaming Control Commission, the National Guard, the State Guard, and Departments of Environmental Protection, Financial Services, Highway Patrol, Highway Safety and Motor Vehicles, Law Enforcement, Lottery Services, Alcoholic Beverages and Tobacco. Virginia signed agreements with the Department of Wildlife Services and Marine Resources Commission. In Texas, the National Guard signed an MOU with CBP authorizing active duty members to enforce immigration law — extending 287(g)-style authority to state armed forces, not just law enforcement. When university campus police, wildlife officers, lottery investigators, and National Guard members all have immigration enforcement authority, the enforcement network has expanded far beyond its stated immigration purpose into a general-population surveillance and enforcement capability.

**Key partner: Immigrant Legal Resource Center (ILRC)** (ilrc.org, Priscilla Olivarez — Senior Policy Attorney & Strategist for 287(g), polivarez@ilrc.org). ILRC maintains the definitive interactive 287(g) map and published "Immigration Dragnet: The New Era of 287(g)" (July 2025). **Immigration court capacity (partially unique).** Judicial throughput for processing mass enforcement, measured through EOIR (Executive Office for Immigration Review) court workload and adjudication statistics, immigration judge appointments, and case processing timeline changes. **Key partner: TRAC at Syracuse** (tracreports.org, directed by Dr. Susan Long). **Detention capacity tracking (triangulated — no single source exists).** No single public dataset provides contracted bed capacity per ICE detention facility over time. ICE stopped reliably publishing its facility characteristics list in late 2024 — right as the detention system began its most rapid expansion. This data gap is itself an information control signal (see above), and it has multiple causes: ICE stopped proactive publication, and **private prison companies (CoreCivic and GEO Group) actively block disclosure by claiming FOIA Exemption 4 (commercial confidentiality) over contracted bed counts.** The gap is not merely governmental negligence — it's partly the result of private contractors asserting that how many people the government can detain is commercially sensitive information. Detention tracking therefore requires triangulating multiple sources that each answer a different question:

- **Capacity expansion** (SAM.gov contracts) — new detention facility contracts specify bed counts (e.g., the $113M KVG contract for 1,500 beds in Maryland). Tracks _new capacity being built_. Also: Freedom for Immigrants' detention map tracks confirmed warehouse purchases with planned bed counts.
- **Authorized capacity** (GovInfo congressional appropriations) — the funded bed level set by Congress. The One Big Beautiful Bill Act allocated $45 billion for detention expansion with a target exceeding 100,000 beds.
- **Contractual capacity snapshots** (TRAC at Syracuse) — TRAC obtained a facility-level snapshot as of April 2025 showing 62,913 total contractual beds across 181 facilities. Confirmed by Adam Sawyer (who worked on this at TRAC) as a one-time FOIA production, not a recurring release, with some capacity values redacted even in the FOIA response. TRAC is seeking a regularly updated series.
- **ICE FOIA library contracts** (ice.gov + Detention Reports archive) — ICE contracts posted in the FOIA library sometimes include bed capacity numbers. Detention Reports is archiving these contracts in case ICE removes them — which is itself an information control data point. Source identified by Adam Sawyer. **Corpus expansion:** fetch and store the full contract PDFs, not just the capacity numbers extracted from them. The contract text includes terms, duration, facility specifications, and pricing — all searchable and assessable.
- **Detention utilization** (Deportation Data Project) — individual-level data on who is detained, at which facility, from when to when. This is utilization, not capacity — it tells you how many people the government _is_ detaining, not how many it _could_ detain. Their arrests and detentions tables are reliable; encounters and removals have known data quality issues that DDP has documented. Integrate via their GitHub repository.
- **Facility-level population** (Detention Reports / Adam Sawyer) — Interval ADP calculations from ICE's biweekly spreadsheets, providing more accurate population estimates than ICE's own fiscal-year averages. When population exceeds contractual capacity at a facility, that's a capacity constraint signal.
- **Historical facility trends** (Vera Institute) — facility-level daily population data by fiscal year (vera-institute/ice-detention-trends on GitHub). Tracks active vs. inactive facilities over time. Does not include bed capacity, but facility count and population trends are useful context.
- **Private prison capacity** (SEC EDGAR) — GEO Group and CoreCivic quarterly filings report bed counts, occupancy rates, and revenue. ACLU FOIA litigation revealed GEO has 22,000+ ICE beds across 20 facilities. Note: these companies are the same ones claiming Exemption 4 on government FOIA requests while disclosing bed counts to investors in SEC filings — a contradiction worth surfacing.

Democracy Monitor's unique contribution is not replicating any of these individual sources — it's connecting detention trends to the other infrastructure dimensions and to document-level erosion detection. When SAM.gov shows new contracts, DDP shows rising utilization, congressional appropriations show expanded funding, and the document analysis pipeline shows elevated concern in immigrationEnforcement simultaneously, the convergence tells a story no individual tracker reveals.

**Legal infrastructure tracking.** Expansion of enforcement authority and reduction of legal constraints. Partially captured by existing sources (DOJ policy memos, consent decree withdrawals via CourtListener, AG opinions). Additional signals: new federal crime categories (LegiScan), mandatory minimum expansions, asset forfeiture fund balances, IRS enforcement budget shifts, OFAC sanctions expansion rate. The metric: how many enforcement tools exist and how broad is their scope — distinct from whether they're being _used_ (which existing categories already track). **Organizations covering this:** The **Brennan Center for Justice** tracks executive power expansion, surveillance authority, and consent decree withdrawals most comprehensively — their "deportation-industrial complex" analysis and HSI mission creep reporting are directly relevant. The **Institute for Justice** (ij.org) maintains the leading civil asset forfeiture tracking project with a comprehensive database of forfeiture laws and cases. **NACDL** (National Association of Criminal Defense Lawyers) advocates for forfeiture reform and maintains policy resources. The **National Immigration Litigation Alliance** (immigrationlitigation.org) tracks legal challenges to immigration policies. These are reference/linking partners — the primary data sources are DOJ reports, CourtListener filings, and LegiScan legislation, which Democracy Monitor already ingests or plans to ingest. **Corpus expansion:** DOJ policy memos, AG opinions, and consent decree documents are full legal documents — store the complete text, not just the metadata indicating a consent decree was withdrawn.

**Financial infrastructure tracking.** Funding patterns that enable enforcement capacity. The metric: enforcement spending growth rate relative to overall budget. **The data landscape is richer than initially assessed.** David Bier at the **CATO Institute** published the most detailed public analysis of OBBBA enforcement spending (March 2026), using OMB apportionment data and Monthly Treasury Statements to show ICE's monthly outlays jumped from ~$800M to $1.7B post-OBBBA, with $24.8B apportioned for detention alone across FY2025-2026. His methodology — tracking OMB apportionments by DHS component, Treasury statement outlays by agency, and USASpending.gov obligation data — is the template for Democracy Monitor's automated financial tracking. Key data sources:

- **OMB apportionment data** — shows how OBBBA funds are being allocated across DHS components. Access method needs investigation (Bier extracted it; may be PDF-based rather than API).
- **Monthly Treasury Statements** (treasury.gov) — agency-level outlays, monthly cadence. The DHS shutdown creates a natural experiment: future statements reflect almost exclusively OBBBA-funded activity.
- **USASpending.gov** (usaspending.gov/federal_account/070-0540) — ICE Operations and Support obligation data with transaction-level detail. Public API available.
- **DHS Congressional Budget Justifications** (published annually) — detailed breakdowns by program activity. Already partially captured through GovInfo.
- **DOJ Asset Forfeiture Fund reports** (justice.gov/afp/reports) — annual reports on forfeiture operations by agency.
- **ICE detention funding vs. expenditure** — the gap between appropriated and spent detention funds signals operational intent.

Other organizations tracking enforcement spending: **American Immigration Council** (published OBBBA immigration spending explainer), **Center for American Progress** (analyzed the OBBBA "slush fund"), **Brennan Center for Justice** (coined "deportation-industrial complex," analyzed the $170B enforcement package), **FWD.us** (comprehensive DHS spending breakdown showing ~$150B unspent reconciliation funds). These are reference/analysis partners, not data integration partners — the primary data comes from Treasury, OMB, and USASpending.gov directly. **Corpus expansion:** Budget Appendix documents (via GovInfo — pre-chunked by agency, fetcher extends trivially), Monthly Treasury Statement data (via Fiscal Data API — structured JSON), OMB apportionment memos, and Asset Forfeiture Fund reports are all corpus expansion targets. **Chunking resolved for Budget Appendix** — GovInfo provides per-agency granules. DHS granule may need sub-chunking by component (ICE, CBP, TSA) for better routing. See Release 1 infrastructure corpus expansion section for full details. Outreach initiated to David Bier at CATO (pending response).

**Cross-feature convergence.** When personnel build-out, surveillance procurement, and detention capacity all accelerate in the same policy domain in the same timeframe, while P2025 proposals for that domain are being implemented (Release 5) and rhetoric about that domain is escalating (Release 3) — that convergence across independent analytical dimensions is the strongest signal the system can produce. This is the novel analytical product that no individual data source or organization provides.

### Complex Adaptive Systems Analysis

**Theoretical foundation.** Democratic institutions are a complex adaptive system: multiple interacting agents (branches of government, agencies, courts, states, civil society), feedback loops (enforcement escalation → judicial pushback → executive defiance → congressional response), emergent properties (the "deportation-industrial complex" wasn't designed as a coherent system — it emerged from thousands of individual procurement, hiring, and legal decisions), and the potential for phase transitions where the system flips from one stable state to another. This framing names something Democracy Monitor is already detecting but doesn't yet have the vocabulary for. Cross-category convergence is coupling between subsystems. The repurposing risk section describes path dependence and adaptive reuse. The weekly narrative's observation that "simultaneous multi-category activation concentrated at a single institutional layer could indicate system-wide stress" is describing emergent behavior. The CAS lens makes these observations systematic and connects them to a body of theory with predictive implications.

**Data inputs — everything already in the system.** The CAS analysis doesn't require new data sources. It's an analytical lens applied to the existing corpus, assessments, and infrastructure dimensions:

- Weekly L2 assessments across all 14 categories (stressors)
- Balance of Powers P2.5 classifications (compensating responses — when Phase A ships)
- Cross-category convergence data (coupling between subsystems)
- Infrastructure dimension trends: 287(g) rate, detention capacity, spending velocity, personnel changes
- Document embeddings (coalition detection via cross-source clustering)
- Source volume and composition data (information control / reporting pattern shifts)
- Historical baselines across the full 9-year corpus

**CAS feature inventory — report only on features with evidence:**

Not all features fire every analysis period. The report evaluates each and includes only those where the evidence is meaningful:

**1. System stress indicators.** How many categories are elevated simultaneously? Is elevation concentrated in one institutional domain or distributed across multiple domains? Is the rate of multi-category activation increasing, stable, or decreasing? Already partially covered by weekly narratives — the CAS framing makes it explicit and systematic with quantitative tracking over time.

**2. Compensating mechanism health.** Are institutional responses keeping pace with stressors? The ratio of executive actions per week to judicial challenges per week, enforcement escalation rate to congressional oversight activity rate. The trend in this ratio indicates whether the system's self-correcting capacity is strengthening, holding, or degrading. Before Balance of Powers Phase A, approximated from document volume by source type (court filings as proxy for judicial response, CREC floor speeches as proxy for congressional engagement). After Phase A, quantitative from P2.5 constraint classifications.

**3. Response latency.** When a stressor appears (executive order, enforcement action), how many days/weeks until a compensating response appears (court filing, congressional hearing, IG investigation)? Increasing response latency means compensating mechanisms are slowing — either overwhelmed by volume or degraded by institutional damage (e.g., IG positions unfilled, court vacancies). Detectable from document timestamps in the existing corpus.

**4. Feedback loop identification.** When enforcement escalation in category A triggers judicial pushback in category B, which triggers executive defiance in category C, which triggers congressional response in category D — that's a feedback loop visible as a temporal chain across categories. The analysis looks for recurring cross-category activation sequences: does the same A → B → C pattern repeat across different policy domains?

**5. Coupling strength.** How tightly coupled are the categories? If immigrationEnforcement elevates and civilLiberties always elevates the same week, they're tightly coupled. If governmentWorkerProtections elevates independently, loosely coupled. The coupling matrix changes over time — categories that were independent under Biden may become tightly coupled under Trump T2 because the same policy apparatus (DOGE, OBBBA) affects multiple domains simultaneously. In CAS theory, increasing coupling is a fragility signal — tightly coupled systems are more prone to cascading failure.

**6. Phase transition indicators.** The most speculative feature. In a CAS, a phase transition happens when the system absorbs stress up to a threshold and then shifts rapidly to a new state. Indicators: accelerating multi-category activation rate, increasing coupling, degrading compensating mechanism ratios, increasing response latency, convergence across infrastructure dimensions. No single indicator proves a phase transition is imminent — but when all move in the same direction simultaneously, that's the signature of a system approaching a threshold. Presented as structural observation, never as prediction.

**7. Coalition detection.** Semantic clustering of documents across institutional sources. When floor speeches from different committees, court filings from different circuits, and IG reports from different agencies all cluster around the same semantic content in the same time period — that's an emergent coalition. When clusters that were coherent start fragmenting — coalition breakdown. Detectable from existing embeddings with cross-source temporal clustering analysis.

**8. Adaptive reuse / repurposing signals.** When infrastructure built for one purpose starts generating documents in categories beyond its original domain — 287(g)-related documents appearing in pressFreedom (officers detaining journalists) or freeAndFairElections (enforcement near polling places) — the infrastructure is being repurposed. Detectable as category migration patterns in the existing document routing data.

**Output format — monthly or quarterly, not weekly:**

CAS dynamics play out over weeks and months. A weekly CAS report would mostly say "no change." The weekly narrative covers the short-term view; the CAS analysis covers medium-term structural dynamics. Monthly cadence keeps cost manageable (12 analyses per year vs. 52).

Each report has a consistent structure, but only populated sections appear:

- **System State Summary.** One paragraph: category elevation count, coupling pattern, compensating mechanism status. Accessible to general readers.
- **Active Dynamics.** Only features where something has changed or crossed a threshold. Each section cites specific documents and data. Not all eight features every month — just the ones with evidence.
- **Structural Risks.** What current dynamics suggest about trajectory — conditional statements, not predictions. "If the current trend in response latency continues, the median time from executive action to judicial challenge will exceed 21 days by Q3 2026. This matters because enforcement actions unchallenged for three weeks create operational facts on the ground that are difficult to reverse."
- **What This Analysis Cannot Tell You.** Explicit limitations section, every report. "This analysis detects patterns in government-published documents. It cannot see classified actions, informal communications, or enforcement activities that don't generate federal documents. Coupling analysis shows correlations, not causal mechanisms. Phase transition indicators are structural observations, not predictions."

**Audience — one version, accessible language, expert depth available on drill-down:**

CAS vocabulary (phase transitions, coupling strength, feedback loops) has intimidating names but the concepts are accessible: coupling strength is "how many things break when one thing breaks," phase transition is "the point where the system stops bending and starts breaking," compensating mechanisms is "the parts of the system that push back." The report is written for the same audience as the weekly narrative — concerned citizens, journalists, researchers. Expert depth comes from the data behind the report: every observation links to underlying documents, assessments, and trend data. An expert can drill into the coupling matrix or response latency distributions. A general reader gets the summary paragraph.

**What this gives Democracy Monitor that nobody else has:**

V-Dem scores outcomes annually. Freedom House surveys experts. Bright Line Watch polls political scientists. Nobody models democratic institutions as a complex adaptive system and tracks system-level dynamics — stress absorption, compensating mechanism health, coupling, feedback loops, phase transition indicators — from primary-source documents. This is a genuinely novel analytical contribution.

### Analytical Principles

**Every dimension is a partial picture.** No single source tells the full story of any infrastructure dimension. USAJobs shows postings, not hires. SAM.gov shows contracts awarded, not systems deployed. FOIA.gov shows response times, not decisions to withhold. 287(g) agreements show signed agreements, not enforcement actions taken under them. Each dimension is a leading indicator assembled from the publicly visible portion of a process that's mostly invisible. The value of the infrastructure feature is not claiming comprehensive tracking — it's assembling the partial views that are publicly available into the most complete picture possible, documenting exactly what each source can and can't tell you, and surfacing convergence across dimensions that no individual source reveals.

**Cross-administration comparison is the signal.** The incompleteness of each source is constant across administrations — USAJobs was equally incomplete under Biden as under Trump T2, SAM.gov was equally incomplete, FOIA.gov was equally incomplete. What changes between administrations is what shows up in those same imperfect sources, and that change is the signal. If USAJobs shows 500 ICE officer postings per quarter under Biden and 3,000 per quarter under Trump T2, the absolute numbers are incomplete but the ratio is real. The analytical claim is not "the government has X capacity" — it's "the government is building capacity at Y rate compared to Z baseline, measured consistently using the same imperfect sources." A critic can't argue the data is incomplete (we've already said it is). They can only argue the incompleteness is _asymmetric_ across administrations — that the same sources systematically show more under one administration for reasons unrelated to actual infrastructure buildup. That's a much harder criticism to make.

**Gaps are findings.** When a source that used to publish data stops publishing it, that's both a data gap AND a signal. ICE stopped publishing its facility characteristics list in late 2024; FOIA response times at an agency may degrade or stop being reported; data.gov datasets may be quietly removed. "We used to be able to see X and now we can't" is the information control dimension detecting its own degradation. Information control can also originate from the private sector: CoreCivic and GEO Group claim FOIA Exemption 4 (commercial confidentiality) over contracted bed counts, asserting that how many people the government can detain is proprietary business information — while simultaneously disclosing bed counts to investors in SEC filings. Each dimension's presentation should show not just what the data reveals, but where the government (or its contractors) has made it harder to see — with explicit documentation of what's visible, what's not, and when visibility changed.

**Opacity enables infrastructure buildup regardless of its source.** A government that can expand detention capacity, surveillance networks, or enforcement reach without public visibility into the scale of that expansion can act before anyone realizes the scope. It doesn't matter whether the opacity originates from the government (ICE stopping publication of facility characteristics), the private sector (CoreCivic and GEO Group claiming Exemption 4 over contracted bed counts), or structural gaps (no single dataset connecting procurement to deployment to utilization). The effect on public accountability is identical. The information control dimension should therefore track opacity from all sources — governmental data cessation, private-sector FOIA resistance, and structural gaps where no disclosure mechanism exists — and present them as a unified picture of how visible or invisible infrastructure buildup is to the public. The threat from hidden capacity doesn't go away just because the hiding is done by a contractor rather than an agency.

**Per-dimension transparency.** The infrastructure page should show each dimension with its sources AND its gaps:

- **Personnel:** "We can see job postings (USAJobs) and funded positions (budget docs). We can't see actual hires, academy completion rates, or attrition."
- **Surveillance:** "We can see procurement contracts (SAM.gov). We can't see deployment, operational status, or interoperability."
- **Detention:** "We can see new contracts (SAM.gov), utilization (DDP), one capacity snapshot (TRAC, with redactions), and some bed counts in FOIA library contracts. We can't see a comprehensive, current accounting of total contracted beds — the government stopped publishing that in late 2024, and private prison companies claim contracted bed counts are commercially confidential even as they disclose them to investors."
- **Information control:** "We can see FOIA response times and data catalog changes. We can't see informal decisions to delay, withhold, or de-prioritize information release."

**Every data source is a corpus expansion opportunity.** Infrastructure monitoring is not a separate analytical layer that sits alongside the document corpus — it IS an expansion of the corpus. For every data source in every dimension, the first question is: **can we fetch the full underlying documents, create embeddings, and run them through the L2 detection pipeline?** Not summaries. Not metadata extracts. The actual documents. 287(g) MOA PDFs go into the corpus as searchable, assessable documents. SAM.gov contract documents go into the corpus. FOIA response documents go into the corpus. ICE FOIA library contracts go into the corpus. The metrics and time series (agreement counts, procurement spend, response times) are the structural signal; the documents themselves are what makes the corpus more complete and the search more useful. A researcher searching for "287(g) enforcement authority in Florida" should find the actual signed agreements, not just a count of how many exist. A journalist investigating a specific surveillance contract should find the contract text, not just a SAM.gov summary. The infrastructure monitoring feature succeeds not just when it surfaces rate-of-change signals, but when it makes Democracy Monitor's searchable document repository the most comprehensive collection of government enforcement infrastructure documents available anywhere.

**The corpus itself is the sensor.** With a 9-year continuous corpus of documents from the same government sources — all dated, tagged by source and type, with embeddings — the document repository detects shifts in government reporting without any external data. The corpus doesn't just contain information about government activity; it IS a record of what the government chose to publish, when, in what form, and at what level of detail. Changes in that pattern are detectable because the baseline exists. This capability requires no new data sources — only a long enough span of consistently-gathered documents to establish what "normal" looks like. Specific detection capabilities:

- **Volume shifts by source.** If Federal Register rules drop from 500/month to 200/month, or OIG reports drop from 30/month to 5/month, the trend is visible from `sourceOrigin` + `publishedAt`. The 9-year span provides four administration-periods for comparison.
- **Document type composition shifts.** If an agency shifts from proposed rules (which require public comment) to direct final rules or interim final rules (which skip the comment period), or if executive orders increase while rulemaking decreases, the shift from deliberative to unilateral governance is measurable from `documentType` over time.
- **Content quality degradation.** If Federal Register preambles get shorter — less analytical justification, less response to public comments, more boilerplate — that's detectable through document length by source over time. If the text shifts from detailed legal reasoning to conclusory assertions, embeddings will cluster differently.
- **Source disappearance.** If a source that published regularly stops — ICE's facility characteristics list, specific agency statistical publications — the pipeline notices the absence. This is L1v2 silence detection applied to long-term source health.
- **Category coverage shifts.** Which categories receive documents from which sources? When government-controlled sources (FR, DOJ, CPD, OIG) stop producing documents in a category while independent sources (CREC, CourtListener) show elevated activity, the divergence is the signal. This is L1v2's conspicuous silence design, dramatically more powerful with a 9-year baseline.
- **Semantic narrowing.** If DOJ press releases were semantically diverse under Biden (civil rights, antitrust, public corruption, immigration) and cluster tightly around immigration under Trump T2, embedding centroids and spread per source per period reveal the narrowing of enforcement priorities.
- **Publication timing patterns.** If an agency that published uniformly shifts to concentrating releases on Friday evenings — the "Friday night document dump" — timestamps on every document make this detectable.

This capability connects directly to L1v2 silence detection (Release 1B), which implements the weekly version of the same concept. The infrastructure build-out extends it to long-term trend detection across the full 9-year span. **Where the corpus cannot see hidden activity directly — classified surveillance contracts, spending moved to invisible channels — the divergence between what the corpus shows and what other indicators suggest is the finding.** The corpus detects the information control even though it can't see the hidden spending itself. This is how Democracy Monitor serves investigators: not by finding every hidden contract, but by pointing to where the gaps are so others know where to dig.

### Repurposing Risk: From Immigration Enforcement to Broader Repression

The authoritarian threat of enforcement infrastructure is not only its scale but its **repurposability.** Infrastructure built for one target population can be redirected toward others. This is not a theoretical concern — it is the consistent historical pattern (Japanese internment used census data, McCarthyism used federal employee databases, post-9/11 surveillance targeted Muslim communities using counterterrorism tools) and it is already underway in the current period.

**The mechanism:** Each infrastructure dimension has a stated purpose (immigration enforcement) and a latent capability (enforcement against any population the government designates). Detention facilities can hold anyone. Surveillance tools can monitor anyone. 287(g) agreements deputize local police to enforce federal law in any context. The transition from stated purpose to broader application doesn't require new infrastructure — it requires only a change in who is designated as the target.

**Evidence the transition is already underway:**

- **HSI mission pivot:** ICE's Homeland Security Investigations division — originally focused on transnational crime (cartels, trafficking, child exploitation) — has been explicitly reordered around civil immigration enforcement and domestic protest monitoring. Internal communications reportedly make "civil immigration enforcement first; everything else secondary" the stated priority. HSI agents were deployed to police racial justice protests after George Floyd (Trump T1) and are currently monitoring anti-ICE protests, tracking social media critics, and conducting facial recognition scans of US citizen bystanders in Minneapolis (Trump T2).
- **Surveillance targeting political speech:** ICE's Zignal Labs contract monitors 8 billion social media posts per day. Global Entry has been revoked for people who criticized ICE on Instagram. Administrative subpoenas — previously reserved for child exploitation cases — are being used to unmask anonymous social media critics. ICE's August 2025 privacy impact assessment says surveillance tools will be used to track "threats to the agency," but press releases show the agency searching for any anti-ICE statements, not threats.
- **Detention of US citizens:** During Operation Metro Surge in Minneapolis, Judge Jerry Blackwell found that the "overwhelming majority" of cases ICE brought to him involved people lawfully present in the US. US citizens have been detained. This is the transition from immigration-specific detention to general population detention.
- **Excess capacity beyond operational need:** DDP's analysis showed monthly arrests haven't substantially increased since Spring 2025, yet the administration is pushing capacity from 40,000 beds to 100,000+. Capacity that exceeds operational need for its stated purpose is available for other purposes.
- **287(g) Task Force Model revival:** The Obama and Biden administrations discontinued this model specifically because of racial profiling and civil rights abuses. Its revival (zero agreements to 948 in 15 months) allows enforcement during routine police activity — traffic stops, any interaction with local police — which extends federal enforcement authority into every encounter between any person and any local officer in a participating jurisdiction.
- **Systematic defiance of judicial oversight:** Chief Judge Schiltz found ICE violated 97 court orders in Minnesota in January 2026 alone. When enforcement agencies systematically defy courts, the infrastructure operates without constraint — the checks that would prevent repurposing have been neutralized.
- **Internal oversight dismantled (signal partially reversed as of July 2026):** ICE closed its Office for Civil Rights and Civil Liberties. Training was cut by 40% in early 2026, including hours on legal authority — but in July 2026 ICE reportedly extended basic training from 42 to 71 days (reported by US Border News; not yet corroborated by documents in our corpus). The training component of this operational condition has partially reversed; the closure of the civil-rights office has not. We flag the reversal here because evidence discipline cuts both ways: a signal we cited as a condition for mission creep weakened, and readers should know that before we do further analysis on top of it.

**Signals Democracy Monitor should track for repurposing:**

The infrastructure build-out feature should include indicators that distinguish immigration-specific use from broader repurposing:

1. **US citizen detention rate** — number and circumstances of US citizens detained by ICE. Any sustained non-zero rate is a signal.
2. **HSI case mix** — ratio of transnational crime investigations to civil immigration enforcement and domestic surveillance. The shift is measurable if case-level data is available (TRAC may have this).
3. **Surveillance deployment at protests** — documented instances of facial recognition, drones, license plate readers, or social media monitoring deployed at domestic political protests rather than immigration enforcement operations.
4. **Data-sharing agreements crossing the immigration boundary** — HHS Medicaid data shared with ICE, IRS tax data shared with ICE (a federal judge found this violated tax law), commercial surveillance networks (Flock/Ring) queried on ICE's behalf. Each agreement extends surveillance reach beyond immigration into general population.
5. **Capacity utilization ratio** — detention capacity divided by immigration enforcement utilization. When capacity substantially exceeds immigration-specific need, the surplus is available capacity for other purposes.
6. **287(g) enforcement actions in non-immigration contexts** — instances where 287(g)-deputized officers use federal authority during protests, political activity, or encounters unrelated to immigration.
7. **Court orders defied** — count of judicial orders ICE has violated, by jurisdiction and time period. Systematic judicial defiance means the infrastructure operates without legal constraint.
8. **Internal oversight status** — whether agencies maintain functional civil rights offices, inspector general cooperation, and training on legal authority. Closure or degradation of these mechanisms removes the internal checks on repurposing.
9. **Administrative subpoenas targeting speech** — use of administrative subpoenas (which require no judicial approval) to identify critics, unmask anonymous accounts, or obtain records of people engaged in political activity.
10. **Social media monitoring scope** — whether surveillance contracts and privacy impact assessments describe immigration-specific use or broader "threat to the agency" mandates. The language in the contracts reveals the intended scope.

Many of these signals already appear in Democracy Monitor's existing document corpus — court filings documenting US citizen detentions, congressional floor speeches objecting to ICE overreach, DOJ press releases expanding enforcement authority, executive orders broadening target designations. The infrastructure build-out adds the quantitative dimensions (how many agreements, how much capacity, how much spending) while the existing detection pipeline captures the documentary record of the authority expansion and the institutional pushback against it.

**Analytical caution:** Tracking repurposing risk requires distinguishing between infrastructure that _could_ be repurposed and evidence that it _is being_ repurposed. The former is a structural observation (excess capacity exists); the latter requires documented instances (US citizens detained, protesters surveilled, political speech targeted). Democracy Monitor should present both clearly and separately — the structural conditions that enable repurposing, and the evidence that repurposing is occurring — without conflating capability with intent where the evidence doesn't support it.

## Release 3: Rhetoric vs. Action

### Why It Matters

Democratic erosion often follows a pattern: officials first _say_ something, then they _do_ something. The rhetoric comes weeks or months before the policy. A president calls an agency "corrupt" and "wasteful" — three weeks later, DOGE enters the agency's offices and puts 10,000 employees on leave. A secretary of state announces a "reorganization" — within days, career staff are terminated and programs are cancelled.

This pattern is not unique to any administration. It is a structural feature of how governments signal, test, and implement policy changes. The lag between rhetoric and action is measurable, and the measurement itself is valuable: it tells the public what is likely coming next, how reliably officials follow through on stated intentions, and whether rhetoric is escalating faster than action (signaling worse to come) or decelerating (signaling a trial balloon that lost momentum).

No existing tool systematically measures this. Media covers rhetoric and actions separately. Fact-checkers verify individual claims. Democracy indices score outcomes annually. Nobody tracks the _temporal relationship_ between what officials say and what the government subsequently does, across every policy domain, with primary-source attribution.

Democracy Monitor can do this because it already ingests the government's formal actions (regulations, court filings, enforcement actions) and presidential statements (via the Compilation of Presidential Documents). Adding attributed rhetoric from the Congressional Record, cabinet agency newsrooms, and official social media accounts creates a complete picture of who said what, when, and whether corresponding government action followed.

This release also addresses a known architectural limitation of document-in-isolation analysis: some erosion events use constitutionally routine documentary forms to accomplish extraordinary things. The Comey firing (2017) is the canonical example — the termination letter is a standard personnel action; the significance is entirely contextual (firing an FBI director investigating the president's campaign). Both P1 and P2 correctly assessed what the document _says_ but missed what it _means_, because the investigation context isn't in the termination letter. Rhetoric and media sources provide that missing context, enabling detection of events where the documentary form is routine but the surrounding circumstances are extraordinary.

### Two Independent Analytical Dimensions

**Rhetoric vs. Action** — what the document IS:

- **Rhetoric:** someone saying something — a floor speech, a Truth Social post, a press conference statement, a press briefing
- **Action:** the government doing something — publishing a rule, signing an executive order, filing an enforcement action, issuing a directive

**Rings** — the channel's formality level:

- **Ring 1 (official record):** Federal Register, Congressional Record, court filings — contains both rhetoric (floor speeches, presidential remarks) and action (rules, executive orders, court orders)
- **Ring 2 (direct-to-public):** Truth Social, press conferences, agency newsroom statements — mostly rhetoric, occasionally action (agency enforcement announcements)
- **Ring 3 (surrogate amplification):** Allied legislators echoing talking points, party leadership statements — almost exclusively rhetoric

These dimensions are independent. A CREC floor speech is Ring 1 and rhetoric. An executive order is Ring 1 and action. A Truth Social post is Ring 2 and rhetoric. A complete progression crosses both dimensions: "the President posted about cleaning house at the FBI (Ring 2 rhetoric) → allied senators echoed it on the floor (Ring 1 rhetoric) → the termination letter was signed (Ring 1 action)."

### Key Features

**Phase 1 — Source integration and rhetoric routing**

**Congressional Record integration.** Full-text floor speeches from the Congressional Record via GovInfo API, parsed by speaker using the `unitedstates/congressional-record` open-source parser. Each document is one speaker's remarks on one topic, with party affiliation, state, and ICPSR ID metadata. Volume: 75-491 entries per week across all five analysis periods (2017-2026). Speaker parsing is a solved problem — Stanford's Congressional Speech Dataset validated this approach across 14 million speeches from 1879 to 2022. **Done (R1-SX1).**

**Presidential social media (Truth Social).** CNN-maintained archive updates every five minutes as structured JSON/CSV/Parquet. Trump's Truth (Defending Democracy Together) provides searchable archive with video transcription and image descriptions. Easiest source integration — structured data, stable URL, no authentication. Covers T2 only (no baseline periods); presidential rhetoric is already captured through CPD for detection purposes. Truth Social's value is for rhetoric-action analysis: the gap between formal FR/CPD language and direct-to-public social media framing is itself a signal — posts often use more aggressive framing that signals direction before formal action follows.

**American Presidency Project (APP) press conferences.** UCSB's APP has transcripts of all presidential news conferences, searchable by president and time period. Covers all baseline periods. No public API — requires HTML scraping or bulk data request (academic projects are the intended audience; reach out to Gerhard Peters at UCSB for bulk access). A Kaggle dataset provides historical data. Medium feasibility, high value for historical baseline coverage.

**Cabinet rhetoric via agency newsrooms.** The State Department publishes full press briefing transcripts and Secretary speeches with archived versions covering all baseline periods (2021-2025 content archived at 2021-2025.state.gov). DHS publishes Secretary statements directly relevant to immigration and law enforcement monitoring. Each agency follows the same pipeline pattern: paginated listing → fetch full page → extract transcript → attribute to speaker → store with speaker metadata. **Fragility risk:** each administration may restructure the website — URL patterns change, archive locations change. Scraping works today but requires ongoing maintenance. DOJ AG speeches remain blocked (no API, Akamai bot protection). High value per document, medium feasibility, requires acceptance of maintenance burden.

**Rhetoric routing enhancement.** Rhetoric documents (especially social media and floor speeches) are fuzzier than formal action documents — a post about "cleaning house in Washington" could match multiple categories. Pure keyword matching (the current CREC approach) produces the most noise. A priority chain produces much cleaner category assignments:

1. **Document reference** — speech or post references a specific bill number, executive order, rule, or document URL already in the corpus → inherit that document's category. Highest confidence. CREC granule metadata includes bill references; Truth Social posts frequently contain links to government documents or news articles.
2. **Entity reference** — speech mentions a specific agency (OPM, ICE, DOJ), official (FBI Director, Inspector General), or program (DACA, Schedule F) by name → route to the category associated with that entity. Medium-high confidence.
3. **Link resolution** — social media post contains a URL → resolve domain and path to determine topic. Government domain URLs often contain enough structure to determine category without fetching the page (whitehouse.gov/presidential-actions/executive-order-on-..., ice.gov/news/releases/...). When the link targets a document already in the corpus, inherit that document's category directly. Medium confidence.
4. **Keyword/topic matching** — existing CREC topic routing terms. Lowest confidence, most noise. Current fallback.

Levels 1-3 ground rhetoric routing in the same specific actions and entities that formal documents reference. This makes per-category rhetoric-action comparisons and ring analysis meaningful — both sides are talking about the same thing because the routing is derived from the same references.

**Phase 2a — Standalone dashboards (no matching required)**

Rhetoric and action are each interesting without being connected to each other. Ship these visualizations first:

- **Rhetoric intensity** per category per week — how much are officials talking about each topic?
- **Rhetoric escalation** tracking — is P2 concern level on rhetoric documents trending up over time?
- **Action intensity** per category per week — the existing detection pipeline
- **Side-by-side rhetoric and action timelines** on shared time axis per category. Within the rhetoric side, documents are color-coded by ring. The researcher sees not just "rhetoric preceded action" but which rings were active and in what order.
- **Ring volume by category over time** — three lines showing activity by ring. Since Ring 1 contains both rhetoric and action, optionally split Ring 1 into "Ring 1 rhetoric" (floor speeches, presidential remarks) and "Ring 1 action" (rules, orders, filings) for clarity. Categories where Ring 2 consistently leads Ring 1 action by N weeks are categories where social media previews policy. Categories where Ring 1 action appears with no Ring 2 or Ring 3 preceding it are categories where the government acts without rhetorical preparation. Categories where Ring 3 is active but Ring 1 action never follows are trial balloons that didn't convert.
- **New topic emergence** — when does "DOGE" first appear in floor speeches, and in which ring?
- **Speaker focus metrics** — which officials talk about which topics, and through which channels?

**Phase 2b — Expert matching tool (gamified)**

The tool shows an expert two side-by-side document lists: rhetoric on the left, actions on the right, both for the same category and time window. Ring classification visible as color coding on both sides. The expert draws connections. Three types:

- **Rhetoric → Action:** "this speech led to this rule" — the primary use case
- **Rhetoric → Rhetoric across rings:** "this Truth Social post (Ring 2) was echoed in this floor speech (Ring 1)" — frame propagation
- **Full chain:** "Ring 2 post → Ring 1 speech → Ring 1 rule" — the complete progression across both dimensions

AI suggests candidate matches ranked by embedding similarity. Experts confirm or reject. Each confirmed connection immediately updates visible metrics:

- Category lag distribution narrows (expert just provided a ground-truth data point: "Secretary said X on March 3, rule published March 21, confirmed lag: 18 days")
- Ring-to-ring propagation timing becomes measurable (median time from Ring 2 rhetoric to Ring 1 action in this category)
- Rhetoric-action correlation improves per category
- "Based on your connection, these 5 other pairs look similar — confirm or reject?" — active learning, each action trains the next suggestion
- Speaker-level metrics update: which officials' rhetoric most reliably predicts action, and through which ring progression?

The gamification is natural because the feedback loop is immediate and meaningful. The expert watches the dashboard get smarter with each connection. The lag distribution sharpens. The ring progression pattern emerges. The suggested matches improve. Each connection has visible impact on a public-facing analytical product.

**Phase 2c — Automation (only if warranted)**

- Only build after experts have confirmed enough matches to train against
- **Rhetoric → Action matching:** if 500+ confirmed pairs produce ≥80% precision on held-out pairs, automate
- **Ring → Ring frame propagation:** if expert-confirmed cross-ring connections show consistent patterns, attempt automated detection
- **Speaker prediction:** if lag data is consistent per speaker, compute per-official rhetoric-to-action conversion metrics automatically
- If precision thresholds aren't met, the expert tool IS the product — "AI-assisted rhetoric-action research tool with human curation" is a valuable and honest product

## Release 4: Balance of Powers & Democracy Index Evidence Mapping

### Why It Matters

Democracy Monitor currently tells you what's going wrong. It doesn't tell you whether the system is responding. When the executive branch fires 17 inspectors general in a single night, the system correctly flags executiveOversight as elevated — but it doesn't show the two federal court injunctions filed within 48 hours, the three GAO investigations launched in the following weeks, or the congressional oversight hearing convened in response. Those institutional responses are democracy _functioning_, and their presence or absence is as important as the threat that triggered them.

**Risk assessment: the full visualization may tell you what you already know.** During the current period, courts blocking executive actions and Congress holding hearings is front-page news every day. A three-branch triangle showing "judicial checks active on immigration, congressional checks weak on oversight" would visualize what informed citizens already see. The scenario where constraint rate metrics add genuine insight is when they silently decline — courts stop issuing injunctions, GAO stops investigating, congressional hearings quietly cease. But that's essentially silence detection applied to inter-branch relationships, with the same noise-vs-signal problems encountered in L1v2 (a court not issuing an injunction this week might mean the action was legal, or the court hasn't gotten to it, or no one filed a challenge). **The Democracy Index Evidence Mapping is the genuinely novel piece** — nobody else provides the primary-source documents alongside democracy index scores so researchers can independently evaluate those assessments.

**Recommended approach:** Ship Phase A (P2.5 check classification, "Checks Activated" panels in category pages) and the V-Dem/Freedom House evidence mapping. These enrich narratives and provide a unique analytical product. The evidence mapping should be framed as enabling independent verification — not as validating specific indices. Defer the full Balance of Powers visualization (three-branch triangle, constraint rates, historical trajectory) until empirical data from Phase A demonstrates that constraint rate metrics tell you something the narratives don't already say.

### Key Features

**Three-branch visualization.** A triangle/network diagram where each vertex represents a branch of government and each edge represents a directional constraint relationship. Edge thickness reflects smoothed constraint rate (rolling 4-week window). Edge color indicates above or below baseline. Tooltips show coverage percentage and match rate so users know which edges have high-confidence data and which are sparse.

**Edge-first drill-down.** Users click an edge (e.g., Judicial → Executive), then filter by monitoring category (immigration, civil service, etc.), then see the specific constraint documents and linked pairs with response latency. This aligns with the "checks and balances in tension" framing — the entry point is the relationship, not the category.

**Historical trajectory.** Animate or scrub the visualization over time to show how constraint rates have shifted across the Trump T2 period. Where have checks strengthened? Where have they weakened? When did the shifts happen?

**Constraint asymmetry.** Per branch pair, the ratio of constraint rates in each direction. A balanced ratio (near 1.0) suggests healthy tension. A highly asymmetric ratio — one branch checking the other far more than the reverse — is a summary signal worth surfacing.

**Expert enrichment.** Human experts can enhance the automated classifications: link a check precisely to the action being checked, add non-documentary knowledge about informal practices (Senate holds, back-channel negotiations), and specify dates for events that produced no document. Expert contributions are tagged with identity and timestamp, creating an audit trail and enabling inter-rater agreement measurement. Sporadic expert input is valuable — even one confirmed link per week calibrates the automated matcher.

**Democracy Index Evidence Mapping.** V-Dem and Freedom House produce the most widely cited democracy assessments — annual scores based on expert surveys that tell you whether judicial independence, civil service integrity, press freedom, and other dimensions improved or declined. What they cannot provide is the evidentiary trail: which specific government actions drove the changes they scored? Democracy Monitor can, because it has the documents indexed, categorized, and assessed. **The value is independent verification, not validation.** The documents may confirm an index's assessment, complicate it, or reveal dynamics the annual score missed entirely. A declining V-Dem score accompanied by aggressive judicial pushback tells a fundamentally different story than the same score with no institutional resistance — but the score alone can't distinguish the two. **Important framing note (per Poulson feedback):** Democracy Monitor should not position itself as providing evidence _for_ established indices. Both V-Dem and Freedom House have contested funding sources and methodological critics; tying Democracy Monitor's credibility to theirs introduces dependencies we don't need. The framing is: "Here are the primary-source documents. Form your own conclusions about whether the indices got it right."

A `/research/indices` page maps V-Dem and Freedom House indicators to Democracy Monitor's 14 categories and presents three layers of evidence:

- **Documentary evidence.** The category trajectory, key elevated weeks, and specific P2-confirmed documents relevant to the external assessment. "V-Dem says judicial independence declined. Democracy Monitor's data shows judicialIndependence was Elevated 48% of weeks, driven by these specific executive actions." The documents are presented for the researcher to evaluate — not as proof that V-Dem's score is correct.

- **Institutional response evidence.** From the Balance of Powers data: constraint rates, specific injunctions and oversight reports, response latency. "Courts filed injunctions against 8 of 10 challenged executive actions, with median response latency of 12 days." This reveals the contested process underneath the score — forces in tension that a single annual number cannot capture.

- **Dynamics summary.** An AI-generated note connecting both sides: "The documentary record shows significant executive pressure on judicial independence, alongside active judicial pushback through habeas corpus proceedings and injunctive relief. A declining V-Dem score with strong institutional pushback tells a different story than a declining score with no pushback at all — the first suggests a contested process; the second suggests capitulation."

This positions Democracy Monitor as a **primary-source research tool** that enables independent evaluation of democracy assessments — not as a validation layer for any specific index. It does not produce a competing score, does not claim to validate or invalidate external assessments, and holds institutional response evidence to the same epistemic standard as threat evidence (with explicit coverage and confidence metrics). The framing is: "V-Dem and Freedom House assess outcomes. Democracy Monitor provides the documentary record of the process — the forces in tension within the system — so researchers can evaluate those assessments for themselves."

A basic version (threat evidence only, without Balance of Powers institutional response data) can ship after Release 1. The full version with both threat and response evidence ships with or after Release 4 when Balance of Powers Phase B is operational.

## Release 5: Project 2025 — Plan vs. Delivered

### Why It Matters

Project 2025, published by the Heritage Foundation, is a 920-page blueprint for restructuring the federal government. It proposes specific policy changes organized by agency — who to fire, what programs to cut, which regulations to reverse, how to restructure the civil service. Regardless of whether any administration formally endorses the document, it functions as a declared-intent baseline: a public, detailed plan against which government actions can be measured.

**Existing landscape.** Several organizations already track P2025 implementation effectively. Project 2025 Observer (project2025.observer) tracks 320 objectives across 34 agencies with human-curated status tracking, source links, and community discussion — rated High for factual reporting by Media Bias/Fact Check. The Center for Progressive Reform maintains a separate executive action tracker across 20 federal agencies. These manual trackers answer the core question — "is this proposal being implemented?" — with human judgment that is likely more accurate than automated matching for this specific task.

**What Democracy Monitor uniquely adds.** The system already ingests the government documents that implement P2025 proposals — Federal Register rules, executive orders, DOJ enforcement changes, OPM workforce guidance. Rather than duplicating the manual tracking that existing tools do well, Release 5 focuses on three capabilities nobody else provides:

1. **Documentary evidence linking.** When external trackers say "Schedule F implemented," Democracy Monitor shows the specific OPM rule, the P2 assessment explaining why it weakens merit protections, the cited passages, and the category's convergence status. This connects the "what happened" tracking to the "what it means for democratic institutions" analysis.

2. **EXCEEDS detection.** When government actions go beyond what P2025 proposed — more aggressive than the blueprint — that's a qualitatively different signal than mere implementation. Tracking which proposals are being exceeded, in which policy domains, reveals where the administration's ambitions extend beyond its declared allies' plan. No existing tracker systematically identifies this pattern.

3. **Cross-feature convergence.** A category with elevated AI concern AND active P2025 implementation AND rhetoric escalation (Release 3) AND infrastructure build-out (Release 2) tells a story no individual tracker reveals. P2025 implementation status becomes a convergence input alongside the existing detection layers, not a standalone feature.

### Key Features

**Proposal import with attribution.** Rather than building an independent extraction pipeline, import existing third-party proposal extractions (Democracy Forward, Brookings, Project 2025 Observer) with full attribution. Embed proposals using the same embedding model as the document pipeline. Human review for quality and category mapping. This leverages the community's existing work rather than duplicating it.

**Document-proposal linking pipeline.** Each week, newly ingested government documents are compared against proposal embeddings via cosine similarity. Top candidates are evaluated by an LLM judge that classifies the relationship (NOT_RELATED / LOOSELY_RELATED / IMPLEMENTS / EXCEEDS) and provides auditable reasoning. The judge links to the specific government document — not a news article about the document.

**"Exceeded" detection.** The most analytically novel feature. When the LLM judge determines that a government action goes beyond what P2025 proposed, that's flagged for review and surfaced prominently. Tracking which proposals are being exceeded, in which policy domains, reveals where implementation outpaces even the declared plan.

**Category integration.** P2025 match counts feed into convergence scoring per monitoring category. A category with high AI concern _and_ active P2025 implementation is qualitatively different from high scores alone — it adds the "declared intent" dimension to the "measured action" dimensions the system already tracks.

### Implementation Details

**Schema:**

- `p2025_proposals` table: id, chapter, target_agency, dashboard_category, severity, text, summary, embedding, source_attribution (tracks which third-party extraction the proposal came from)
- `p2025_matches` table: proposal_id, document_url, cosine_similarity, llm_classification, llm_confidence, llm_reasoning, human_reviewed
- `p2025_tracking` table: proposal_id, week_of, status, match_count (enables time-series analysis)

**Pipeline:**

1. Import sprint — ingest existing third-party proposal extractions with attribution. Human review for quality and category mapping.
2. Embed all proposals using the same embedding model as the document pipeline.
3. Weekly linker: cosine similarity against new documents → top-K candidates → LLM judge classification → store matches with reasoning.
4. EXCEEDS flagging: proposals where LLM judge identifies government actions going beyond the proposal are surfaced for review.
5. Category integration: P2025 implementation activity as a convergence input.

**UI:** `/p2025` page with headline statistic ("Of Y proposals tracked, X% show implementation activity"), EXCEEDS highlights, per-category implementation overlay, and drill-down to individual proposals with their matched government documents, P2 assessments, and the AI's reasoning for each match. Link to external trackers (Project 2025 Observer, CPR) for comprehensive status tracking — Democracy Monitor complements rather than replaces.

**Effort:** Medium. Significantly reduced from original design by importing rather than extracting proposals, and by focusing on documentary evidence linking and EXCEEDS detection rather than comprehensive status tracking. The matcher pipeline reuses existing embedding infrastructure.

## Release 6: State-Level Research Corpus

### Why It Matters

Significant threats to democratic governance originate at the state level — voter suppression laws, election board takeovers, anti-protest legislation, gerrymandering, state AG actions to weaken federal protections. V-Dem and Freedom House both track sub-national democratic quality, and their assessments increasingly flag state-level erosion in the United States. Democracy Monitor's federal-only scope misses this dimension entirely.

However, state-level monitoring is a fundamentally different problem than federal monitoring. The system's analytical framework — 14 categories, convergence scoring, source classification (executive-branch-controlled vs. independent-branch), CREC contrast signals — assumes a single executive branch producing documents the system reads. Extending this to 50 state governments would require 50 sets of baselines, 50 source health monitors, state-specific P1/P2 prompts calibrated for state institutional dynamics, and a selection methodology that doesn't encode editorial judgments ("we monitor these 15 states because we think they're the most concerning"). Each state has its own governance structure, its own document publishing patterns, and its own baseline for what constitutes normal governance.

The right entry point is as a **research corpus** — not a detection expansion. Make state-level data available for download, search, and analysis without integrating it into the federal detection pipeline.

### Connection to Release 4: Democracy Index Evidence Mapping

Release 4 connects V-Dem and Freedom House assessments to Democracy Monitor's documentary evidence. Both indices increasingly flag state-level democratic quality concerns in the US:

- **V-Dem** tracks subnational democratic governance indicators including electoral management body autonomy, legislative constraints on the executive, and judicial independence at the state level. When V-Dem downgrades US electoral integrity, the underlying drivers are often state-level voting restrictions.
- **Freedom House** flags specific state actions in its annual Freedom in the World reports — voter ID laws, gerrymandering, restrictions on ballot initiatives, protest suppression.

With a state-level research corpus, Release 4's evidence mapping could show: "V-Dem flags declining electoral integrity in the US → here are the 23 state bills in the elections category that may be driving that assessment, with their text, status, and the states that enacted them." This connects the international index score to specific, verifiable documentary evidence at the state level — the same philosophy Democracy Monitor applies to federal evidence, extended to states.

The Release 4 evidence mapping would naturally surface which states and which policy domains are most active, providing an evidence-based framework for deciding where to focus state-level analysis — rather than selecting states based on editorial judgment.

### Data Sources

**LegiScan state bills (existing infrastructure).** The LegiScan fetcher already supports `--state TX`, `--state FL`, etc. State bills are classified into monitoring categories using the same topic routing terms as federal legislation. The main constraints are API rate limits and bulk dataset size. A targeted approach — 10-15 states identified through Release 4's V-Dem/Freedom House mapping as having the most democratic erosion-relevant legislation — is feasible without monitoring all 50.

**CourtListener state appellate courts (existing infrastructure).** The CourtListener API supports state appellate court opinions. New signal definitions for state supreme court decisions on voting rights, election law, redistricting, and civil liberties would extend the existing federal court pipeline. The search capability exists; only new signal definitions are needed.

**State executive orders and regulations (self-healing scraper system).** No centralized, machine-readable database of governor executive orders exists across all 50 states. Each state publishes on its own governor's website in different formats — HTML, PDF, or both. Open States/Plural Open aggregates legislative data for all 50 states but does not cover executive orders. The Sunlight Foundation found that executive orders in 38 states are not subject to any form of administrative procedure act and are rarely subject to the same filing and publication requirements as legislation. This fragmentation is why the gap exists — maintaining 50 scrapers against 50 websites that change without notice is a maintenance burden that no organization has sustained.

Democracy Monitor addresses this with an AI-powered self-healing scraper architecture:

**V1 rapid build.** Claude Code builds scrapers for all 50 states in a single sprint. Each governor's website follows a similar pattern (list page with titles/dates, detail pages with full text). The structural variation (HTML layouts, URL patterns, pagination, PDF vs. HTML) is exactly the kind of problem where an LLM examining page source and writing a targeted scraper excels. PDF executive orders are handled by the existing PDF extraction pipeline.

**Common validation layer.** Every state fetcher answers the same validation questions: did I get a list of documents? Does each document have a title, date, and full text? Is the document count plausible (not zero, not suspiciously high)? Has the count changed since last run? Is the content substantive (not navigation text or error pages)? Are dates parsing correctly? These checks are source-agnostic and catch the majority of breakage — site redesigns, layout changes, URL pattern changes.

**Tiered self-healing:**

- **Tier 1 — Automated (most states).** Validation catches breakage, a GitHub agent fetches the current page, identifies what changed in the HTML structure, generates a fix, runs validation against the fix, and if it passes, commits the change and triggers a re-run. Handles the 80% case: CSS selector changes, URL pattern changes, pagination changes, minor layout restructuring.
- **Tier 2 — Agent-assisted (some states).** The agent detects breakage and attempts a fix, but the fix doesn't pass validation. It opens a GitHub issue with diagnostic information (what broke, what it tried, what the current page looks like) and assigns it for human review. Claude Code fixes it interactively.
- **Tier 3 — Manual (few states).** States with fundamentally inaccessible executive orders (authenticated access, JavaScript-rendered without static fallback, no archive of past orders). Flagged as gaps in the source health dashboard.

**Standalone public good.** A maintained, open-source, machine-readable database of all 50 states' governor executive orders does not exist anywhere. Building and maintaining this is a contribution to democratic infrastructure that researchers, journalists, and other democracy-monitoring organizations would use independently of Democracy Monitor's detection pipeline. This is the kind of infrastructure project that attracts funding and collaborators on its own merits.

**State regulations** remain a larger gap — each state has its own administrative register with different formats and publication schedules. The self-healing scraper architecture could extend to state regulation gazettes, but the document volume and format complexity are significantly higher than executive orders. Defer to a future phase unless a specific state's regulatory activity becomes urgently relevant.

### Scope and Approach

**Research corpus, not detection pipeline.** State-level documents are available through the Data page (CSV export, API endpoint, GitHub database dump) and through Research Mode search. They are not integrated into the federal detection pipeline — no convergence scoring, no weekly narratives, no category-level elevation status for state data. Researchers can download the data and perform their own analysis.

**Category reuse.** State bills and court opinions use the same 14 monitoring categories as federal documents. A Texas voter ID bill routes to elections; a Florida anti-protest bill routes to civilLiberties. This enables cross-level research ("compare federal and state elections category activity over time") without requiring a separate category framework.

**V-Dem/Freedom House informed prioritization.** Rather than selecting states editorially, use Release 4's Democracy Index Evidence Mapping to identify which states V-Dem and Freedom House flag for declining democratic quality. Begin corpus building with those states. Expand as the evidence mapping reveals additional areas of concern.

## Cross-Feature Convergence

Releases 2, 3, and 5 are most powerful when they converge. Any single signal is informative; all analytical dimensions lighting up simultaneously for the same policy domain tells a story that no individual data source reveals. Release 4 (Balance of Powers) adds a dimension of institutional response — whether checks and balances are keeping pace with the threats the other releases detect.

**The convergence scenario:** (1) A government document matches Project 2025 Chapter 5's proposal to increase ICE detention capacity (Release 5 — P2025). (2) The president and DHS Secretary begin talking about "mass deportation operations" (Release 3 — Rhetoric). (3) In weeks 3-8, USAJobs shows an ICE officer posting surge, SAM.gov reveals new detention contracts and surveillance technology procurement, and Deportation Data Project data shows detention utilization tripling (Release 2 — Infrastructure). (4) Meanwhile, the existing detection layers show DHS rulemaking volume spiking, CourtListener immigration filings surging, and DOJ press releases shifting topic distribution toward immigration enforcement (existing system — government document analysis). (5) The Balance of Powers data shows the judicial constraint rate on immigration-related executive actions declining from baseline (Release 4 — institutional checks weakening as action accelerates).

The cross-feature convergence score operates per category per week: not "are multiple layers concerned about lawEnforcement" (existing within-category convergence) but "are rhetoric, P2025 implementation, infrastructure build-out, and measured government action all accelerating in the same policy domain at the same time — and are the institutional checks keeping pace?"

**Design constraint:** The data model decisions for Release 3 (speaker attribution, statement-to-action linking) must anticipate Release 5 matching and Release 2 infrastructure tracking. Design the cross-feature convergence schema before building any release.

**Build order:** Release 2 (Infrastructure — personnel, surveillance, information control) first — most novel dimensions, highest-feasibility APIs, and can ship standalone source additions (like CREC was pulled into Release 1). Release 3 Phase 1 (Rhetoric sources — Truth Social, APP, State/DHS newsrooms + routing enhancement) second — delivers immediate value through existing pipeline. Release 3 Phase 2a (standalone dashboards) third — rhetoric, action, and ring visualizations ship without any matching. Release 3 Phase 2b (expert matching tool) when Phase 2a proves the side-by-side view is useful and expert users are available. Release 3 Phase 2c (automation) only if expert data warrants. Release 4 Phase B (Balance of Powers visualization) conditional on Phase A proving the constraint rate metric adds insight. Release 5 (P2025) last — existing trackers cover the core need; Democracy Monitor's unique value is cross-feature convergence, which requires the other releases to exist. Release 6 (State-Level) after federal system is stable. Cross-feature convergence ships after Releases 2-5 have baseline data.
